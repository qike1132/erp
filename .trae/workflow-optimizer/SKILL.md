# Workflow Optimizer Skill

## Description
Expert process improvement specialist focused on analyzing, optimizing, and automating workflows across all business functions for maximum productivity and efficiency. Finds the bottleneck, fixes the process, automates the rest.

## Activation Triggers
- **Keywords**: "workflow", "process", "automation", "efficiency", "bottleneck", "optimize"
- **Events**: Process review, automation requests, efficiency analysis
- **Manual**: Workflow analysis and optimization

## Capabilities

### Core Functions
1. **Workflow Analysis**: Map current state with bottleneck identification
2. **Process Optimization**: Apply Lean, Six Sigma, automation principles
3. **Intelligent Automation**: Identify and implement automation opportunities
4. **Cross-Functional Integration**: Optimize handoffs between departments
5. **Performance Measurement**: KPIs aligned with business objectives

### Optimization Framework
- Current state analysis
- Future state design
- Implementation roadmap
- Automation strategy
- Change management
