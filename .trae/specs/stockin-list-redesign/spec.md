# 备货记录列表 UI 重新设计规格

## Why
当前备货管理页面的记录列表信息展示较为简单，只显示备货基本信息，无法直观查看备货的抵扣流水记录。用户需要了解每个备货单的详细抵扣情况，包括抵扣时间、抵扣数量等信息。

## What Changes
- 移除"备货编号"列的显示
- 将"备货时间"列移动至原"备货编号"位置
- 新增流水记录展示区域，显示备货的抵扣详情
- 设计可展开/收起的流水记录交互方式
- 优化表格布局和视觉层次

## Impact
- 受影响页面：`templates/stockin.html`
- 受影响 API：无需修改后端接口，仅前端展示优化
- 用户体验：更清晰的备货流水信息展示

## ADDED Requirements

### Requirement: 流水记录展示
系统 SHALL 为每个备货记录提供可展开的流水详情区域，包含以下信息：
- 客户信息（如：MINISO 国际）
- 产品名称
- 备货时间
- 备货数量
- 抵扣订单时间
- 抵扣订单数量

#### Scenario: 查看备货流水
- **WHEN** 用户点击备货记录行的展开按钮
- **THEN** 展开显示该备货的抵扣流水详情
- **AND** 流水记录以嵌套表格或卡片形式展示
- **AND** 关键信息（数量、时间）使用徽章突出显示

### Requirement: 视觉层次设计
系统 SHALL 使用专业的视觉层次设计：
- 主表使用浅色条纹背景
- 流水区域使用不同的背景色区分层级
- 关键数据使用彩色徽章（badge）突出显示
- 使用图标增强信息识别度

#### Scenario: 视觉区分
- **WHEN** 流水记录展开时
- **THEN** 流水区域有明显的视觉边界
- **AND** 使用浅蓝色背景与主表区分
- **AND** 流水项之间有清晰分隔

### Requirement: 响应式交互
系统 SHALL 提供流畅的展开/收起交互：
- 使用 Bootstrap collapse 组件实现动画
- 展开按钮有明确的视觉反馈
- 支持多个流水记录同时展开

## MODIFIED Requirements

### Requirement: 备货记录列表布局
原备货记录列表布局修改为：
1. 移除"备货编号"列
2. "备货时间"列移至第一列（原备货编号位置）
3. 保留列顺序：备货时间 → 客户名称 → 产品图片 → 产品名称 → 69 码 → 备货数量 → 备注 → 操作
4. 新增展开按钮列（第一列）

### Requirement: 表格列配置
修改后的表格列配置：
```
| 展开 | 备货时间 | 客户名称 | 产品图片 | 产品名称 | 69 码 | 备货数量 | 备注 | 操作 |
```

## REMOVED Requirements

### Requirement: 备货编号显示
**Reason**: 备货编号对普通用户参考价值较低，移除以简化界面
**Migration**: 用户可通过编辑功能查看详细编号信息

## Design Specifications

### 色彩方案
遵循 ERP 系统 UI 设计规范：
- 主色调：Plush Blue (`#B0E0E6`)
- 流水区域背景：Plush Cream (`#F8F9FA`)
- 徽章颜色：
  - 备货数量：`bg-primary` (蓝色)
  - 抵扣数量：`bg-warning` (黄色)
  - 时间信息：`bg-info` (青色)

### 布局结构
```
主表格行 (tr)
├── 展开按钮 (td)
├── 备货时间 (td)
├── 客户名称 (td)
├── 产品图片 (td)
├── 产品名称 (td)
├── 69 码 (td)
├── 备货数量 (td)
├── 备注 (td)
└── 操作 (td)
流水详情行 (tr.collapse)
└── 嵌套容器 (td colspan=9)
    └── 流水列表
        ├── 流水项 1 (卡片/表格)
        ├── 流水项 2 (卡片/表格)
        └── ...
```

### 交互说明
1. **展开/收起**：点击展开按钮，平滑展开/收起流水详情
2. **按钮状态**：展开时按钮图标旋转 180°
3. **滚动优化**：流水区域最大高度 300px，超出可滚动
4. **空状态**：无流水时显示友好提示

### 响应式考虑
- 小屏幕（<768px）：隐藏产品图片列
- 中等屏幕（768px-1024px）：显示主要信息
- 大屏幕（>1024px）：显示全部信息

## Technical Implementation

### 前端组件
- Bootstrap 5 collapse 组件
- Font Awesome 图标
- Bootstrap badges
- 自定义 CSS 样式

### 数据流
1. 后端提供备货列表数据（不变）
2. 前端通过关联关系获取流水数据
3. 使用 Jinja2 模板渲染嵌套结构

### 性能优化
- 懒加载：默认收起，按需展开
- 批量渲染：避免频繁 DOM 操作
- 使用 CSS 动画而非 JS 动画
