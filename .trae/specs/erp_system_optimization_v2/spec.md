# ERP系统功能优化与数据结构调整规格说明书

## 概述
- **摘要**：对ERP系统进行五项核心功能优化与数据结构调整，包括字段清理、订单编号重构、客户名称选择优化、产品搜索功能改进以及备货抵扣触发机制调整
- **目的**：简化订单创建流程，优化用户体验，提升系统可用性和数据一致性
- **目标用户**：系统管理员和订单管理人员

## 目标
- 移除"验货数据"和"设计稿"相关字段
- 将"订单编号"字段更名为"订单时间"，实现自动生成格式"YYYY-MM-DD-XXX"
- 客户名称字段增加固定选项："MINISO国际"、"MINISO国内"、"MINISO电商"
- 产品选择从下拉框改为关键字实时搜索
- 调整备货抵扣触发机制：用户在订单数量字段输入数值后点击"抵扣备货"按钮

## 非目标（超出范围）
- 不修改库存管理系统的核心逻辑
- 不改变备货抵扣的业务逻辑（仅调整触发方式）
- 不修改现有历史数据的结构

## 背景与上下文
- 当前系统：基于Flask的ERP系统，包含产品、订单、备货、出货、库存管理模块
- 现有问题：
  1. 订单管理页面存在"验货数据"和"设计稿"两个空标签页
  2. 订单编号需要手动输入
  3. 客户名称需要手动输入
  4. 产品选择使用下拉框，产品多时不方便
  5. 备货抵扣按钮位置和触发方式需要优化

## 功能需求

### FR-1：数据字段清理
- 移除订单管理页面中的"验货数据"标签页及相关代码
- 移除订单管理页面中的"设计稿"标签页及相关代码

### FR-2：订单编号系统重构
- 将"订单编号"字段标签更名为"订单时间"
- 实现自动订单号生成功能，格式固定为"YYYY-MM-DD-XXX"（如"2026-03-11-001"）
- 日期部分自动获取订单创建时的北京时间（东八区时间）
- 序号部分（XXX）从001开始，每日独立滚动自增

### FR-3：客户名称选择优化
- 在客户名称字段中增加固定选项："MINISO国际"、"MINISO国内"、"MINISO电商"
- 实现单选选择功能，用户必须从中选择一个选项

### FR-4：产品选择功能改进
- 将现有产品下拉选择功能修改为关键字搜索模式
- 实现实时搜索功能：用户输入关键字时，系统自动显示匹配的产品名称列表
- 搜索结果需准确且响应迅速

### FR-5：备货抵扣功能调整
- 移除当前"备货抵扣"按钮（从订单表单中移除独立按钮）
- 保留并维持原有的备货抵扣业务逻辑不变
- 实现新的触发机制：
  - 用户在订单数量字段输入数值后，"抵扣备货"按钮变为可用状态
  - 点击"抵扣备货"按钮后，系统显示可用于抵扣的备货数量

## 非功能需求
- **NFR-1**：界面修改应保持与现有系统风格一致
- **NFR-2**：搜索响应时间应在500ms以内
- **NFR-3**：所有修改应在不同设备上响应式显示
- **NFR-4**：备货抵扣功能应与现有库存管理系统正确集成

## 约束
- **技术**：Flask + SQLite + Bootstrap 5 + Font Awesome
- **开发环境**：Windows
- **依赖**：现有静态资源（bootstrap、css）

## 假设
- 系统已经有备货数据可用于抵扣
- 订单号生成逻辑不会与现有订单号冲突
- 用户权限系统保持不变

## 验收标准

### AC-1：移除"验货数据"和"设计稿"字段
- **Given**：用户访问订单管理页面
- **When**：查看订单管理页面
- **Then**：页面上不应显示"验货数据"和"设计稿"标签页
- **Verification**：`human-judgment`

### AC-2：订单时间字段更名与自动生成
- **Given**：用户打开订单创建表单
- **When**：页面加载完成
- **Then**：
  - 字段标签显示为"订单时间"
  - 字段值自动填充为"YYYY-MM-DD-XXX"格式（如2026-03-11-001）
  - 字段为只读状态，用户不可编辑
- **Verification**：`programmatic`

### AC-3：客户名称固定选项
- **Given**：用户打开订单创建表单
- **When**：点击客户名称下拉框
- **Then**：下拉选项显示"MINISO国际"、"MINISO国内"、"MINISO电商"三个固定选项
- **Verification**：`human-judgment`

### AC-4：产品关键字实时搜索
- **Given**：用户打开订单创建表单
- **When**：在产品搜索框中输入关键字
- **Then**：系统显示匹配的产品名称列表，支持实时搜索
- **Verification**：`human-judgment`

### AC-5：备货抵扣触发机制
- **Given**：用户填写订单数量字段
- **When**：输入订单数量后点击"抵扣备货"按钮
- **Then**：系统显示可用于抵扣的备货数量
- **Verification**：`programmatic`
