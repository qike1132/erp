# 生产模板导出功能实现计划

## 需求分析

在 products 页面中，当用户点击"生产模板"按钮时，需要实现以下功能：

1. 触发 Windows 操作系统自带的文件保存对话框这个是NO.1需要解决的
2. 允许用户自定义文件保存路径和文件名
3. 用户确认保存后，将本地模板文件复制到用户选择的目标路径
4. 提供明确的成功/失败反馈信息

## 当前实现分析

当前系统已存在的功能：

* 现有的"生产模板"按钮会自动获取桌面路径并复制模板到桌面

* 后端已有 `/get-desktop-path` 和 `/copy-template-to-desktop` API

* 模板文件位置：`c:\Users\Administrator\Desktop\erp_system\static\files\模板.xlsx`

## 实现方案

### 技术方案选择

由于浏览器安全限制，前端 JavaScript 无法直接调用 Windows 文件保存对话框。需要通过以下方案实现：

**方案：后端调用 Python pyautogui/pywin32 库打开 Windows 文件保存对话框**

1. 前端点击按钮后调用后端 API
2. 后端使用 Python 的 `pywin32` 库调用 Windows 原生文件保存对话框
3. 用户选择路径后，后端复制文件到指定位置
4. 返回结果给前端显示

### 实现步骤

#### 步骤 1：安装必要的 Python 依赖

安装 `pywin32` 库用于调用 Windows API：


#### 步骤 2：创建后端 API 路由

创建新的 API 端点 `/save-template-dialog`：

**功能实现：**

1. 使用 `win32com.client` 调用 Windows 文件保存对话框
2. 获取用户选择的保存路径和文件名
3. 将模板文件复制到用户指定的路径
4. 处理各种异常情况（路径不可写、文件正在使用等）
5. 返回成功/失败结果给前端

**错误处理：**

* 用户取消对话框

* 目标路径不可写

* 文件正在被使用

* 磁盘空间不足

* 权限不足

#### 步骤 3：修改前端代码

修改 `templates/product.html` 中的"生产模板"按钮事件处理：

2. 更新按钮文本和提示信息
3. 优化用户体验（加载状态、错误提示等）

#### 步骤 4：测试与验证

测试场景包括：

## 详细实现代码

### 后端 API 实现要点

```python
@app.route('/save-template-dialog', methods=['POST'])
def save_template_dialog():
    try:
        # 1. 调用 Windows 文件保存对话框
        import win32com.client
        
        # 创建文件对话框对象
        dialog = win32com.client.Dispatch("Shell.Application")
        
        # 或者使用 tkinter 的 FileDialog
        from tkinter import filedialog
        from tkinter import Tk
        
        # 隐藏主窗口
        root = Tk()
        root.withdraw()
        root.attributes('-topmost', True)
        
        # 打开文件保存对话框
        file_path = filedialog.asksaveasfilename(
            defaultextension=".xlsx",
            filetypes=[("Excel files", "*.xlsx"), ("All files", "*.*")],
            title="保存生产模板",
            initialfile=f"产品导入模板_{datetime.now().strftime('%Y%m%d_%H%M%S')}.xlsx"
        )
        
        root.destroy()
        
        # 用户取消
        if not file_path:
            return jsonify({
                'success': False,
                'error': '用户取消保存'
            }), 400
        
        # 2. 复制模板文件
        template_path = os.path.join(app.root_path, 'static', 'files', '模板.xlsx')
        shutil.copy2(template_path, file_path)
        
        # 3. 返回成功结果
        return jsonify({
            'success': True,
            'message': '模板保存成功',
            'savedPath': file_path
        })
        
    except Exception as e:
        # 错误处理
        return jsonify({
            'success': False,
            'error': f'保存失败：{str(e)}'
        }), 500
```

### 前端修改要点

修改 `templates/product.html` 中的下载模板按钮事件：

```javascript
downloadTemplate.addEventListener('click', async (e) => {
    e.preventDefault();
    e.stopPropagation();
    
    downloadTemplate.disabled = true;
    downloadTemplate.innerHTML = '<i class="fas fa-hourglass-half me-2"></i>正在打开保存对话框...';
    
    try {
        const response = await fetch('/save-template-dialog', {
            method: 'POST'
        });
        
        const result = await response.json();
        
        if (response.ok && result.success) {
            showStatus('✓ 模板已成功保存到：' + result.savedPath, 'success');
        } else {
            showStatus('✗ 保存失败：' + (result.error || '未知错误'), 'error');
        }
        
    } catch (error) {
        console.error('操作错误:', error);
        showStatus('✗ 操作失败：' + error.message, 'error');
    } finally {
        downloadTemplate.disabled = false;
        downloadTemplate.innerHTML = '<i class="fas fa-file-excel me-2"></i>生产模板';
    }
});
```

## 风险评估与应对

### 风险 1：tkinter 在某些环境下不可用

**应对方案：**

* 使用 `pywin32` 作为备选方案

* 降级到现有的自动保存到桌面方案

### 风险 2：文件权限问题

**应对方案：**

* 完善的错误捕获和提示

* 建议用户选择有写入权限的目录

### 风险 3：文件被占用

**应对方案：**

* 捕获 `PermissionError` 异常

* 提示用户关闭正在使用的文件
