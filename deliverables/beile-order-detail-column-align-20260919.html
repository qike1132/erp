1 · 一句话结论

「订单数量 / 生产数量」两列的表头文字左对齐、而其下方数字右对齐，故视觉上表头与数据列错位。 根因是 CSS 选择器权重覆盖，与列宽无关：

  • .bo-table thead th { text-align: left } —— 权重 (0,1,2)（1 类 + 2 元素）
  • .c-qty { text-align: right } —— 权重 (0,1,0)（1 类）

前者胜出 ⇒ <th class="c-qty"> 的右对齐被覆盖为左对齐；而 <td class="c-qty"> 无该覆盖、正常右对齐。图片列表头同因（表头左对齐 vs 缩略图居中）。

4 · 根因（代码级）

frontend-vite/src/views/beile-order/components/BeileOrderDetailDialog.vue

<thead>
  <th class="c-img">图片</th>
  <th class="c-name">产品名称</th>
  <th class="c-barcode">产品条码</th>
  <th class="c-qty">订单数量</th>   <!-- 复用 c-qty -->
  <th class="c-qty">生产数量</th>   <!-- 复用 c-qty -->
  <th class="c-note">备注</th>
</thead>

/* 表头基类：权重 (0,1,2) —— 覆盖了列级类 */
.bo-table thead th { padding: 9px 12px; text-align: left; ... }

/* 列级类：权重 (0,1,0) —— 在 tbody 生效，在 thead 被覆盖 */
.c-qty { width: 110px; text-align: right; ... }
.c-img { width: 56px;  text-align: center; }

⇒ 表头「订单数量 / 生产数量」实际渲染为 text-align: left，其下数字为 right；「图片」表头为 left，其下缩略图为 center。

5 · 修复

在列级对齐类之后追加更高权重的表头对齐规则，按列还原表头对齐（数值列右对齐、图片列居中）：

+ /* 表头对齐修正（列对齐）：
+    `.bo-table thead th` 的 text-align:left（权重 0,1,2）会覆盖列级对齐类
+    （.c-qty / .c-img 均为 0,1,0），使数值列表头左对齐、其下数字右对齐，
+    图片列表头左对齐、其下缩略图居中 —— 表头与数据列错位。
+    此处按列还原表头对齐，与 tbody 单元格一致。 */
+ .bo-table thead th.c-qty { text-align: right; }   /* 权重 (0,2,2) > (0,1,2) */
+ .bo-table thead th.c-img { text-align: center; }

选择器权重 .bo-table thead th.c-qty = (0,2,2)，高于 .bo-table thead th = (0,1,2)，故稳定生效；不依赖源码顺序，也不使用 !important。
