## 六、另外一个发现（非缺陷，但值得记录）

4 个还原端点的 `confirm` 默认值写法不统一：`import_backup` / `async_import_backup` 是
`confirm: bool = False`，`restore_server_backup` / `async_restore_server_backup` 是
`confirm: bool = Query(False)`。

线上无影响（FastAPI 在真实请求下都把两者解析为 `False`），但**直接调用**（不走依赖解析）时
后者形参拿到的是 `Query` 对象（真值），会使「省略参数」风格的测试产生假报警。
新增用例因此改为读取声明默认值（Param 取 `.default`）而非直接省略参数调用。
若要统一，可把两处 `Query(False)` 改成 `bool = False`（POST 无 body 模型时 FastAPI 同样按 query 处理），属可选清理。
