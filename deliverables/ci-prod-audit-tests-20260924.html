三、关键排查：PyYAML 的隐性依赖

scripts/prod_audit/config_loader.py:17 直接 import yaml， 但 requirements/ 里没有 PyYAML。若 CI 环境缺它，新步骤会直接 ModuleNotFoundError 变红、并连带阻断 build。

实测结论：CI 会传递带入 —— uvicorn 0.46.0 的 standard extra 明确声明 pyyaml>=5.1，而 requirements/base.txt:9 正是 uvicorn[standard]==0.46.0。 本地 import yaml 亦 OK（6.0.3）。

但仍显式声明：直接导入却依赖传递依赖很脆弱（若有人把 uvicorn[standard] 改成 uvicorn，审核工具与 CI 步骤会静默 ImportError）。已在 requirements/base.txt 的「环境配置」段加：

# PyYAML：scripts/prod_audit/config_loader.py 直接 import yaml
# （审核工具读 audit_config.yaml / rules_registry.yaml；CI 的 prod_audit 测试步骤依赖它）。
# 虽然 uvicorn[standard] 会传递带入 pyyaml>=5.1，但「直接导入」应显式声明，
# 否则将来把 uvicorn[standard] 改成 uvicorn 时，审核工具与测试步骤会静默 ImportError。
pyyaml==6.0.3
