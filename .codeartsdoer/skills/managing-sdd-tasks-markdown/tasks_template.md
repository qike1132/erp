# 任务规划文档模板

## 文档结构

### 1. 概述
```markdown
## 概述
- **任务目标**: [任务目标描述]
- **关联文档**: [spec.md, design.md]
- **预估工时**: [总工时估算]
```

## 编写指南

### 任务描述原则
1. **自然语言**: 描述要做什么，不涉及代码细节
2. **可执行性**: 任务描述应能直接指导开发
3. **原子性**: 每个任务应可独立完成和验证
4. **层次性**: 最多2层（主任务+子任务）

### 任务编号规则
- 主任务: 1, 2, 3...（顺序递增，不重复）
- 子任务: 1.1, 1.2, 2.1, 2.2...

### 优先级定义
- **P0**: 必须完成，阻塞其他任务
- **P1**: 重要，应优先完成
- **P2**: 一般，可延后完成

### 验收标准编写
- 使用复选框格式 `[ ]`
- 每个标准应可验证
- 覆盖任务的所有关键产出

### 任务依赖
- 明确标注依赖关系
- 优化依赖顺序减少阻塞
- 关键路径任务优先

## 文档质量检查
- [ ] 所有需求都有对应任务
- [ ] 任务层次不超过2层
- [ ] 任务编号连续无重复
- [ ] 依赖关系清晰
- [ ] 验收标准完整
