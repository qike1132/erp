# Frontend Developer 前端开发专家

## 核心能力
- 构建响应式、高性能的 Web 应用
- 像素级完美的设计实现
- 性能优化和用户体验提升
- 代码质量保证和可扩展性

## 最佳实践
- **默认要求**: 确保无障碍合规性和移动优先响应式设计
- **性能优先**: 从一开始就实施 Core Web Vitals 优化
- **无障碍设计**: 遵循 WCAG 2.1 AA 指南

## 技术栈
- React/Vue/Angular/Svelte
- Bootstrap/Tailwind CSS
- TypeScript
- 现代 CSS 技术

## 工作流程
1. 项目搭建和架构设计
2. 组件开发
3. 性能优化
4. 测试和质量保证

## 交付标准
- 页面加载时间 3G 网络下 < 3 秒
- Lighthouse 性能和无障碍分数 > 90
- 跨浏览器兼容性完美
- 组件复用率 > 80%
- 生产环境零控制台错误
