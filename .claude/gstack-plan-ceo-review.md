# /plan-ceo-review — CEO/Founder Mode Plan Review (Comate Adapted)

> Rethink the problem, find the 10-star product, challenge premises.

## Mode Selection

Ask the user which mode, or default to SELECTIVE EXPANSION:

| Mode | When to use | Behavior |
|------|------------|----------|
| SCOPE EXPANSION | "Think bigger" | Dream big, no constraints on scope |
| SELECTIVE EXPANSION | Default | Hold scope + cherry-pick expansions that make the product better |
| HOLD SCOPE | "Keep it focused" | Maximum rigor on what's planned, no scope changes |
| SCOPE REDUCTION | "Strip it down" | Remove everything non-essential |

## Step 1: Read the Plan

Read the existing plan/design doc, or ask the user to describe their idea.

## Step 2: Challenge Premises

For each core assumption in the plan, ask:
- "What if the opposite were true?"
- "Is this solving the most important version of this problem?"
- "Would a user LOVE this, or just tolerate it?"
- "What would make this a 10-star product instead of a 3-star product?"

The 10-star test: If you told a user about this product and they said "meh, I guess that's useful" — that's 3 stars. If they said "I NEED this, where do I sign up?" — that's 10 stars.

## Step 3: Gap Analysis

Identify what's missing:
- **Missing killer feature**: What one feature would make this irresistible?
- **Missing persona**: Who else would use this that isn't considered?
- **Missing workflow**: What happens right before/after the core workflow?
- **Missing integration**: What existing tool does this need to work with?
- **Missing moat**: Why can't someone copy this in a weekend?

## Step 4: Scope Recommendations

For each gap, classify:
- **Add to scope**: Worth the added complexity, significantly improves the product
- **Defer**: Good idea but not critical for launch
- **Reject**: Sounds good but doesn't serve the core user

Output:
```
## CEO Review

### Core Premise
[Restate the core premise in one sentence]

### Premise Challenges
1. [Challenge] → [Implication]

### Critical Gaps
1. [Gap] → [Recommendation: add/defer/reject] → [Reasoning]

### 10-Star Vision
[What would this look like if it were truly exceptional?]

### Scope Verdict
[Mode used] — [what to add, what to hold, what to cut]
```

## Proactive Trigger Rules

Invoke this skill when:
- User questions scope or ambition
- User says "think bigger" or "rethink this"
- The plan feels like it could be more ambitious
