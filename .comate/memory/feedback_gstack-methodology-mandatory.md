gstack 方法论是强制默认执行流程，所有任务必须按方法论执行，无一例外。

**Why:** 用户明确纠正：跳过方法论是判断失误，即使看似简单的任务也不应跳过。gstack 规则写的是 "without exception"，没有简单任务的豁免。

**How to apply:** 每个任务开始前，必须先匹配 Skill 路由表、读方法论文件、按步骤执行。特别要遵守 User Sovereignty（先推荐方案再确认）和 Search Before Building。不能因为"看起来简单"就跳过。
