## 📝 使用说明

### 1. 安装新依赖

```bash
pip install Flask-WTF==1.2.1
```

### 2. 配置环境变量

确保`.env`文件包含以下配置:

```env
SECRET_KEY=<redacted-2026-09-11>
DB_PASSWORD=your_secure_password_here
```

### 3. 使用新工具类

#### 使用编号生成器

```python
from utils.number_generator import generate_order_number

order_no = generate_order_number(db)
```

#### 使用批量导入

```python
from utils.batch_import_handler import OrderImportHandler

handler = OrderImportHandler(db, Product, Order)
result = handler.import_from_excel(file)
```

#### 使用分页查询

```python
from utils.pagination import paginate_query, format_pagination_result

query = Product.query.order_by(Product.create_time.desc())
pagination = paginate_query(query)
result = format_pagination_result(pagination)
```

### 4. 数据库迁移

如果使用MySQL,需要重建索引:

```python
# 在Python shell中执行
from app import db
db.create_all()
```
