## 1. 功能介绍

### 1.1 功能概述

批量上传功能是 ERP 系统提供的一项高效数据导入工具，允许用户通过 Excel 文件一次性导入大量业务数据。该功能显著提高了数据录入效率，特别适用于以下场景：

- **初始化系统数据**：系统上线时批量导入基础数据
- **日常业务处理**：批量导入订单、出入库单据
- **数据迁移**：从其他系统迁移数据
- **定期补录**：离线数据定期录入系统

**核心优势**:
- 🚀 **高效快捷**：一次导入数百条数据，仅需几秒钟
- 📊 **准确可靠**：自动数据验证，减少人为错误
- 💾 **事务安全**：数据库事务处理，确保数据一致性
- 🎯 **智能提示**：友好的错误提示，快速定位问题

---

### 1.2 支持的模块

批量上传功能已覆盖以下业务模块：

| 模块名称 | 功能说明 | 访问路径 |
|---------|---------|---------|
| **产品管理** | 批量导入产品信息、初始库存 | /products |
| **订单管理** | 批量导入销售订单 | /orders |
| **入库单管理** | 批量导入采购入库、调拨入库 | /stockins |
| **出库单管理** | 批量导入销售出库、调拨出库 | /stockouts |

---

### 1.3 主要特性

#### 1.3.1 文件上传方式

**点击上传**:
- 点击上传区域，弹出文件选择对话框
- 选择 Excel 文件后自动解析

**拖拽上传**:
- 直接将 Excel 文件拖拽到上传区域
- 松开鼠标后自动开始解析

#### 1.3.2 数据验证

**自动验证**:
- 必填字段检查
- 数据格式验证
- 业务规则校验
- 库存充足性检查

**实时反馈**:
- 验证失败时显示详细错误信息
- 指出具体哪一行数据有问题
- 提供修改建议

#### 1.3.3 导入模式

**全部成功**: 所有数据验证通过，一次性导入

**部分成功**: 部分数据有效，导入有效数据，跳过无效数据

**全部失败**: 所有数据均无效，不导入任何数据

#### 1.3.4 错误处理

**详细错误报告**:
- 显示每一行的错误原因
- 支持 HTML、文本、JSON 多种格式
- 可导出错误报告

**智能容错**:
- 自动跳过无效数据
- 不影响其他数据导入
- 数据回滚保护

### 1.4 使用场景

#### 场景 1：新产品上架

**背景**: 公司新引进 100 个产品，需要录入系统

**传统方式**: 手动逐个录入，预计耗时 2-3 小时

**使用批量上传**: 
1. 下载产品模板
2. 填写 100 个产品信息
3. 上传文件，10 秒完成导入

**效率提升**: 从 3 小时缩短到 10 分钟（包含填写时间）

---

#### 场景 2：批量订单处理

**背景**: 电商部门每天处理 200+ 订单

**传统方式**: 手工录入每个订单，容易出错

**使用批量上传**:
1. 从电商平台导出订单 Excel
2. 调整格式匹配模板
3. 批量导入系统

**效率提升**: 从 4 小时缩短到 30 分钟

---

#### 场景 3：库存盘点后调整

**背景**: 月度盘点后发现库存差异，需要调整

**使用批量上传**:
1. 导出盘点差异表
2. 制作入库单或出库单
3. 批量导入调整单据

**优势**: 快速准确，避免手工录入错误

## 2. 快速入门

### 2.1 访问批量上传功能

#### 方法 1：通过菜单导航

1. 登录 ERP 系统
2. 点击左侧菜单栏
3. 选择对应模块（产品管理/订单管理/入库单/出库单）
4. 在页面顶部或右侧找到"批量上传"卡片

#### 方法 2：直接访问 URL

| 模块 | URL |
|------|-----|
| 产品管理 | http://localhost:5000/products |
| 订单管理 | http://localhost:5000/orders |
| 入库单管理 | http://localhost:5000/stockins |
| 出库单管理 | http://localhost:5000/stockouts |

### 2.2 首次使用指南

**第一步：确认权限**
- 确保您的账号具有批量上传权限
- 默认管理员账号拥有所有权限
- 如需权限，联系系统管理员

**第二步：准备环境**
- 安装 Microsoft Excel 或 WPS Office
- 确保浏览器为最新版本（推荐 Chrome、Edge、Firefox）
- 检查网络连接稳定

**第三步：下载模板**
- 首次使用建议先下载官方模板
- 参考模板格式填写数据
- 不要修改表头结构

**第四步：测试导入**
- 先使用少量数据测试（3-5 条）
- 确认导入成功后再批量操作
- 熟悉整个操作流程

## 3. 使用步骤详解

### 3.1 步骤 1：下载模板

#### 3.1.1 下载方法

**方法 1：点击"下载模板"按钮**

1. 展开批量上传区域
2. 点击"下载模板"或"生成模板"按钮
3. 选择保存位置（建议保存到桌面）
4. 点击"保存"

**方法 2：使用预设模板**

系统已提供标准模板，位于：
- `static/files/产品批量上传模板.xlsx`
- `static/files/订单批量上传模板.xlsx`
- `static/files/入库单批量上传模板.xlsx`
- `static/files/出库单批量上传模板.xlsx`

#### 3.1.2 模板说明

每个模板包含：
- **表头行**：第一行，定义字段名称
- **示例数据行**：第二行（部分模板提供），展示数据格式
- **空白数据行**：从第三行开始，供用户填写

**重要提示**:
- ⚠️ 不要删除或修改表头
- ⚠️ 不要修改列的顺序
- ⚠️ 可以删除示例数据行

---

### 3.2 步骤 2：填写数据

#### 3.2.1 打开模板

1. 使用 Excel 或 WPS 打开下载的模板文件
2. 查看表头，了解需要填写的字段
3. 阅读示例数据（如有）

#### 3.2.2 填写规则

**基本规则**:
1. **按列填写**：每列对应一个字段
2. **逐行填写**：每行代表一条记录
3. **不要留空行**：连续填写，中间不要有空行
4. **不要修改表头**：第一行必须保持不变

**字段填写要求**:

| 字段类型 | 填写要求 | 示例 |
|---------|---------|------|
| 文本字段 | 按要求填写，注意长度限制 | 客户名称："某某科技公司" |
| 数字字段 | 填写有效数字，注意正负 | 数量：100 |
| 日期字段 | 使用指定格式 | 日期：2026-03-14 |
| 必填字段 | 不能为空 | 产品名称、数量等 |
| 选填字段 | 可以为空 | 备注、订单编号等 |

#### 3.2.3 填写技巧

**技巧 1：使用数据验证**
- 在 Excel 中设置数据验证
- 限制输入内容，减少错误
- 例如：日期字段设置为日期格式

**技巧 2：批量填充**
- 相同内容使用填充柄快速填充
- 使用 Excel 公式生成序列号
- 例如：订单编号可以自动生成

**技巧 3：复制粘贴**
- 从其他系统导出数据
- 调整格式后粘贴到模板
- 注意列的对应关系

**技巧 4：数据检查**
- 填写完成后使用 Excel 的筛选功能
- 检查是否有明显错误
- 例如：筛选出数量为负数的行

---

### 3.3 步骤 3：上传文件

#### 3.3.1 点击上传

1. **展开批量上传区域**
   - 点击"批量上传"卡片头部
   - 区域展开，显示上传区域

2. **点击上传区域**
   - 点击虚线边框的上传区域
   - 弹出文件选择对话框

3. **选择文件**
   - 导航到文件保存位置
   - 选择填写好的 Excel 文件
   - 点击"打开"

4. **等待解析**
   - 系统自动解析文件
   - 显示文件信息（文件名、大小、格式）
   - 显示数据行数

#### 3.3.2 拖拽上传

1. **打开文件资源管理器**
   - 找到填写好的 Excel 文件

2. **拖拽文件**
   - 按住鼠标左键，拖动文件
   - 移动到上传区域上方

3. **释放文件**
   - 当上传区域高亮显示时
   - 松开鼠标左键
   - 系统自动开始解析

**拖拽上传优势**:
- 更直观、更快捷
- 减少操作步骤
- 适合频繁使用者

#### 3.3.3 文件选择建议

**推荐的文件格式**:
- ✅ `.xlsx` - Excel 2007 及以上版本（推荐）
- ✅ `.xls` - Excel 97-2003 版本

**不推荐的文件格式**:
- ❌ `.csv` - 当前版本不支持（计划中）
- ❌ `.txt` - 不支持
- ❌ 其他格式 - 不支持

**文件大小限制**:
- 建议大小：< 5MB
- 最大限制：10MB
- 对应数据量：约 1000-2000 行

---

### 3.4 步骤 4：确认导入

#### 3.4.1 查看预览信息

上传成功后，系统会显示：

**文件信息**:
- 文件名
- 文件大小
- 文件格式
- 数据行数

**数据预览**（部分模板支持）:
- 前 5 行数据预览
- 字段对应关系

#### 3.4.2 点击导入按钮

1. **确认信息无误**
   - 检查文件名是否正确
   - 检查数据行数是否匹配
   - 确认是你要导入的文件

2. **点击"开始导入"按钮**
   - 按钮从灰色变为蓝色/绿色
   - 按钮文字显示"导入中..."
   - 系统开始验证和导入数据

3. **等待导入完成**
   - 显示进度条或加载动画
   - 不要关闭页面或刷新
   - 通常 10-30 秒完成

**重要提示**:
- ⚠️ 导入过程中不要关闭浏览器
- ⚠️ 导入过程中不要刷新页面
- ⚠️ 导入过程中不要点击其他按钮

---

### 3.5 步骤 5：查看结果

#### 3.5.1 导入成功

**成功提示**:
```
✅ 导入成功！
共导入 100 条记录
成功：100 条
跳过：0 条
失败：0 条
```

**后续操作**:
1. 系统自动刷新页面
2. 查看新导入的数据列表
3. 检查数据是否正确显示
4. 可以进行进一步操作（编辑、删除等）

#### 3.5.2 部分成功

**部分成功提示**:
```
⚠️ 导入完成（部分成功）
共处理 100 条记录
成功：85 条
跳过：15 条
失败：0 条

查看错误详情 >
```

**后续操作**:
1. 点击"查看错误详情"
2. 下载错误报告
3. 修正错误数据
4. 重新导入失败的数据

#### 3.5.3 全部失败

**失败提示**:
```
❌ 导入失败
共处理 100 条记录
成功：0 条
失败：100 条

错误原因：
- 所有数据的客户名称都不存在
- 文件格式错误
```

**后续操作**:
1. 仔细阅读错误原因
2. 下载详细错误报告
3. 修正所有错误
4. 重新上传文件

#### 3.5.4 错误报告

**错误报告包含**:
- 行号：指出哪一行有错误
- 字段：指出哪个字段有错误
- 错误原因：详细说明错误类型
- 建议：提供修改建议

**错误报告示例**:
```
导入错误报告
============

行号 | 字段 | 错误原因 | 建议值
-----|------|---------|-------
3    | 客户名称 | 客户不存在 | 检查客户名称是否正确
5    | 数量 | 数量必须大于 0 | 100
8    | 产品名称 | 产品不存在 | 使用已存在的产品名称
12   | 日期 | 日期格式错误 | 2026-03-14
```

## 4. 模板格式说明

### 4.1 产品模板格式

#### 4.1.1 表头结构

```
| 产品名称 | 69 码 | 初始库存 | 备注 |
|---------|------|---------|------|
```

#### 4.1.2 字段说明

| 字段名称 | 是否必填 | 数据类型 | 长度限制 | 说明 |
|---------|---------|---------|---------|------|
| 产品名称 | 是 | 文本 | 2-100 字符 | 产品的唯一标识名称 |
| 69 码 | 否 | 文本 | 13 位 | 商品条形码（69 开头） |
| 初始库存 | 否 | 整数 | >=0 | 产品初始库存数量 |
| 备注 | 否 | 文本 | 500 字符 | 产品备注信息 |

#### 4.1.3 填写示例

```
| 产品名称 | 69 码 | 初始库存 | 备注 |
|---------|------|---------|------|
| 笔记本电脑 | 6901234567890 | 100 | 高性能办公笔记本 |
| 无线鼠标 | 6901234567891 | 200 | 人体工学设计 |
| 机械键盘 | 6901234567892 | 150 | 青轴机械键盘 |
```

---

### 4.2 订单模板格式

#### 4.2.1 表头结构

```
| 订单编号 | 客户名称 | 产品名称 | 数量 | 日期 | 备注 |
|---------|---------|---------|------|------|------|
```

#### 4.2.2 字段说明

| 字段名称 | 是否必填 | 数据类型 | 长度限制 | 说明 |
|---------|---------|---------|---------|------|
| 订单编号 | 否 | 文本 | 50 字符 | 留空则自动生成 |
| 客户名称 | 是 | 文本 | 2-100 字符 | 必须已存在于系统 |
| 产品名称 | 是 | 文本 | 2-100 字符 | 必须已存在于系统 |
| 数量 | 是 | 整数 | >0 | 订购数量 |

**规则 2：长度限制**
- 最少 2 个字符
- 最多 100 个字符

**规则 3：字符合法性**
- 允许：中文、英文、数字、空格
- 允许：常见标点符号（- _ . , ( ) （ ））
- 不允许：特殊字符（@ # $ % ^ & * 等）

#### 5.1.2 验证示例

**有效客户名称**:
- ✅ MINISO 国际（6 字符）
- ✅ 某某科技有限公司（8 字符）
- ✅ ABC 贸易公司（7 字符）
- ✅ 张三（2 字符，最小长度）

**无效客户名称**:
- ❌ A（1 字符，太短）
- ❌ （空字符串）

- ❌ 不存在的客户（系统中不存在）

## 6. 常见问题解答

### 6.1 模板相关问题

#### Q1: 模板下载失败怎么办？

**问题描述**: 点击下载模板按钮后没有反应，或下载失败

**解决方案**:
1. 检查浏览器是否阻止了下载
2. 查看浏览器下载文件夹
3. 尝试右键点击按钮，选择"另存为"
4. 联系管理员获取模板文件
5. 使用预设模板（位于 static/files/目录）

**预防措施**:
- 允许浏览器下载文件
- 设置默认下载路径

---

#### Q2: 可以修改模板的表头吗？

**回答**: ❌ 不可以

**原因**:
- 系统根据表头识别字段
- 修改表头会导致系统无法识别
- 列的顺序也不能修改

**正确做法**:
- 保持表头完全不变
- 只填写数据行
- 可以删除示例数据行

---

#### Q3: 模板中可以添加公式吗？

**回答**: ⚠️ 不建议

**说明**:
- 系统读取的是单元格的显示值
- 公式计算的结果可能被正确读取
- 但为了稳定性，建议直接填写数值

**建议**:
- 在 Excel 中计算好结果
- 将结果以数值形式粘贴到模板
- 不要保留公式

---

### 6.2 上传相关问题

#### Q4: 上传文件时没有反应怎么办？

**问题描述**: 点击上传区域或拖拽文件后，系统没有任何响应

**可能原因**:
1. 浏览器兼容性问题
2. JavaScript 被禁用
3. 文件太大
4. 网络问题

**解决方案**:
1. 刷新页面（Ctrl+F5）
2. 清除浏览器缓存
3. 更换浏览器（推荐 Chrome、Edge）
4. 检查文件大小（应<10MB）
5. 检查网络连接

---

#### Q5: 支持哪些文件格式？

**支持**:
- ✅ `.xlsx` - Excel 2007 及以上版本（推荐）
- ✅ `.xls` - Excel 97-2003 版本

**不支持**:
- ❌ `.csv` - CSV 文件（计划中）
- ❌ `.txt` - 文本文件
- ❌ `.pdf` - PDF 文件
- ❌ 其他任何格式

---

#### Q6: 文件太大怎么办？

**问题描述**: 上传的文件超过 10MB

**解决方案**:
1. **分批导入**: 将文件拆分为多个小文件
2. **删除不必要的列**: 只保留必需的字段
3. **压缩图片**: 如果 Excel 中有图片，删除或压缩
4. **另存为新文件**: 有时可以减小文件大小

**建议**:
- 每次导入不超过 1000 行
- 定期清理，避免积累大量数据

---

#### Q7: 为什么提示"客户不存在"？

**原因**:
- 被跳过的数据存在验证错误
- 系统自动跳过错误数据，导入正确数据

**解决方案**:
1. 点击"查看错误详情"
2. 下载错误报告
3. 根据错误报告修正数据

- 订单/出入库模块：允许重复（因为是不同单据）

**建议**:
- 导入前先检查是否有重复
- 使用 Excel 的条件格式标记重复值
- 删除重复数据后再导入

### 7.2 常见错误及解决方案

#### 错误 1: "请上传 Excel 文件"

**错误代码**: FILE_TYPE_ERROR

**错误原因**: 上传的文件不是 Excel 格式

**解决方案**:
1. 确认文件扩展名为 `.xlsx` 或 `.xls`
2. 不要修改文件扩展名
3. 重新保存为 Excel 格式

**预防措施**:
- 使用官方模板
- 不要转换文件格式

---

#### 错误 2: "文件为空"

**错误代码**: FILE_EMPTY

**错误原因**: Excel 文件没有任何数据

**解决方案**:
1. 打开 Excel 文件
2. 确认有数据行（除了表头）
3. 确保数据从第二行开始填写
4. 重新上传

---

#### 错误 3: "客户名称不能为空"

**错误代码**: CUSTOMER_NAME_REQUIRED

**错误原因**: 某行的客户名称字段为空

**解决方案**:
1. 查看错误报告中的行号
2. 打开 Excel 文件
3. 找到对应行
4. 填写正确的客户名称
5. 重新上传

---

#### 错误 4: "客户不存在：XXX"

**错误代码**: CUSTOMER_NOT_FOUND

**错误原因**: 填写的客户名称在系统中不存在

**解决方案**:
1. 检查客户名称拼写
2. 到客户管理模块查看客户列表
3. 复制正确的客户名称
4. 如客户确实不存在，先创建客户
5. 重新上传

---

#### 错误 5: "产品不存在：XXX"

**错误代码**: PRODUCT_NOT_FOUND

**错误原因**: 填写的产品名称在系统中不存在

**解决方案**:
1. 检查产品名称拼写
2. 到产品管理模块查看产品列表
3. 复制正确的产品名称
4. 或使用条形码
5. 如产品确实不存在，先导入产品
6. 重新上传

---

#### 错误 6: "数量必须大于 0"

**错误代码**: QUANTITY_INVALID

**错误原因**: 数量字段为 0、负数或无效值

**解决方案**:
1. 查看错误报告中的行号
2. 打开 Excel 文件
3. 找到对应行
4. 填写大于 0 的整数
5. 重新上传

---

#### 错误 7: "库存不足"

**错误代码**: INSUFFICIENT_STOCK

**错误原因**: 出库数量超过当前库存

**解决方案**:
1. 查看当前库存数量
2. 减少出库数量
3. 或先导入入库单增加库存
4. 重新上传

**示例**:
- 当前库存：50
- ❌ 出库 60（失败）
- ✅ 出库 50（成功）

---

#### 错误 8: "日期格式错误"

**错误代码**: DATE_FORMAT_ERROR

**错误原因**: 日期格式不被支持

**解决方案**:
1. 使用标准格式：YYYY-MM-DD
2. 在 Excel 中设置单元格格式为日期
3. 或留空使用默认日期
4. 重新上传

---

#### 错误 9: "产品名称不能为空"

**错误代码**: PRODUCT_NAME_REQUIRED

**错误原因**: 产品名称字段为空

**解决方案**:
1. 查看错误报告中的行号
2. 打开 Excel 文件
3. 找到对应行
4. 填写产品名称
5. 重新上传

---

#### 错误 10: "重复的产品名称"

**错误代码**: DUPLICATE_PRODUCT

**错误原因**: 尝试导入已存在的产品

**解决方案**:
1. 这是正常现象，不是错误
2. 系统会自动跳过重复产品
3. 查看导入结果中的跳过数量
4. 如需要更新产品，使用产品编辑功能

3. 分别导入
4. 记录每批的导入结果

**分批大小建议**:
- 产品：500-1000 条/批
- 订单：200-500 条/批
- 出入库单：200-500 条/批

#### 8.3.3 导入时机

**推荐时机**:
- ✅ 工作日上午（系统负载低）
- ✅ 非业务高峰期
- ✅ 网络稳定时

**避免时机**:
- ❌ 月末/年末（业务高峰）
- ❌ 系统维护期间
- ❌ 网络不稳定时

### 9.3 数据去重

#### 9.3.1 导入前去重

**为什么要去重**:
- 避免重复导入
- 减少错误
- 提高效率

**Excel 去重方法**:

**方法 1：使用"删除重复项"功能**
1. 选中数据列
2. 点击"数据" → "删除重复项"
3. 选择要检查的列
4. 点击"确定"
5. Excel 会自动删除重复行

**方法 2：使用条件格式标记**
1. 选中数据列
2. 点击"开始" → "条件格式"
3. 选择"突出显示单元格规则"
4. 选择"重复值"
5. 重复数据会高亮显示
6. 手动删除或修正

**方法 3：使用公式**
1. 在辅助列输入公式：
   ```excel
   =COUNTIF($A$2:A2, A2)>1
   ```
2. 向下填充
3. 筛选出 TRUE 的行
4. 删除重复项

#### 9.3.2 系统去重机制

**产品模块**:
- 系统自动检测重复产品名称
- 重复产品会被跳过
- 不会导入重复数据

**订单/出入库模块**:
- 允许相同的客户/产品
- 因为这是不同的单据
- 不视为重复

| 下载失败 | 浏览器阻止 | 允许下载或另存为 |
| 客户不存在 | 名称错误或未创建 | 检查名称或创建客户 |
| 产品不存在 | 名称错误或未创建 | 检查名称或导入产品 |
| 数量错误 | 非正整数 | 填写大于 0 的整数 |
| 日期错误 | 格式不支持 | 使用 YYYY-MM-DD |
| 库存不足 | 出库>库存 | 减少数量或先入库 |
| 导入后看不到 | 未刷新或有筛选 | 刷新页面并清除筛选 |
