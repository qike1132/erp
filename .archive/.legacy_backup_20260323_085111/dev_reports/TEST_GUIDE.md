# 批量上传功能测试指南

## 概述

本文档提供了批量上传功能的完整测试方案，包括手动测试、自动化测试和回归测试。

## 问题回顾

**问题现象**：在"/products"页面中，点击批量上传区域没有任何响应。

**根本原因**：点击事件冒泡到父级的 Bootstrap collapse 组件，导致上传区域立即收起。

**修复方案**：在事件处理器中添加 `e.stopPropagation()` 阻止事件冒泡。

## 常见问题排查

### 问题 1：点击上传区域仍然收起

**可能原因**：
- 浏览器缓存了旧版本的代码
- 修复代码未正确保存

**解决方案**：
1. 清除浏览器缓存（Ctrl+Shift+Delete）
2. 硬刷新页面（Ctrl+F5）
3. 检查 `templates/product.html` 第 348 行是否有 `e.stopPropagation()`

### 问题 2：文件选择对话框不弹出

**可能原因**：
- 浏览器阻止了弹窗
- JavaScript 错误阻止了事件处理

**解决方案**：
1. 检查浏览器地址栏是否有弹窗阻止提示
2. 打开开发者工具（F12）查看控制台错误
3. 确保 `excelInput` 元素存在且可访问

### 问题 3：拖拽上传不工作

**可能原因**：
- 浏览器不支持拖拽 API
- 事件处理器未正确绑定

**解决方案**：
1. 使用现代浏览器（Chrome、Firefox、Edge）
2. 检查 `dragover`、`dragleave`、`drop` 事件监听器
3. 确保 `e.preventDefault()` 和 `e.stopPropagation()` 都已调用

### 问题 4：导入按钮始终禁用

**可能原因**：
- 文件未正确选择
- `handleExcelFile` 函数未执行

**解决方案**：
1. 检查控制台是否有错误
2. 确认文件是 Excel 格式（.xlsx 或.xls）
3. 检查 `excelFile` 变量是否被正确赋值
