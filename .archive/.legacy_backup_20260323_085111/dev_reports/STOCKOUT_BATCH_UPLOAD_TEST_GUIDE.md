# 出库单批量上传功能测试指南

## 功能概述
已成功为出库单模块实现批量上传功能，支持从 Excel 文件批量导入出货数据。

## 测试步骤

### 1. 访问出库单页面
- 打开浏览器访问：http://localhost:5000/stockouts
- 登录系统（如果需要）

### 2. 下载出库单模板
- 在页面右侧找到"批量导入出货"卡片
- 点击"出货模板"按钮下载 Excel 模板
- 模板包含以下列：
  - 出库单编号（可选，留空自动生成）
  - 日期（可选，默认今天）
  - 客户名称（必填）
  - 产品名称（必填，支持产品名称或 69 码）
  - 数量（必填，必须大于 0）
  - 备注（可选）

### 3. 准备测试数据
在 Excel 模板中填写测试数据，例如：

| 出库单编号 | 日期 | 客户名称 | 产品名称 | 数量 | 备注 |
|-----------|------|---------|---------|------|------|
| | 2026-03-14 | MINISO 国际 | 笔记本电脑 | 5 | 测试出库 1 |
| | 2026-03-14 | MINISO 国内 | 鼠标 | 10 | 测试出库 2 |
| | 2026-03-14 | MINISO 电商 | 键盘 | 8 | 测试出库 3 |
| | | MINISO 国际 | 显示器 | 3 | 测试出库 4 - 日期为空 |
| | 2026-03-15 | MINISO 国内 | 笔记本电脑 | 100 | 测试出库 5 - 库存不足 |

### 4. 上传测试
1. 点击"批量导入出货"卡片展开上传区域
2. 拖拽 Excel 文件到上传区域，或点击选择文件
3. 系统会显示文件信息和格式说明
4. 点击"开始导入"按钮

### 5. 验证结果
- 成功导入：显示"导入成功！共导入 X 个出货"
- 部分成功：显示导入数量和跳过数量
- 失败：显示错误信息

### 6. 检查数据库
- 刷新页面查看新增的出库记录
- 检查产品库存是否正确减少
- 查看库存日志是否生成

## 测试场景

### 场景 1：正常导入
- 所有数据都有效
- 库存充足
- 预期结果：全部导入成功

### 场景 2：库存不足
- 某行数据的出库数量超过当前库存
- 预期结果：该行被跳过，显示库存不足错误

### 场景 3：产品不存在
- 某行数据的产品名称在数据库中不存在
- 预期结果：该行被跳过，显示产品不存在错误

### 场景 4：必填字段为空
- 客户名称、产品名称或数量为空
- 预期结果：该行被跳过，显示相应错误

### 场景 5：日期格式错误
- 日期格式不正确
- 预期结果：使用当前日期作为默认值

## 重要提示

1. **库存检查**：系统会自动检查库存是否充足，库存不足时会自动跳过该行
2. **事务处理**：所有成功的记录会在一个事务中提交，确保数据一致性
3. **错误处理**：支持部分成功场景，失败的记录会被跳过并记录错误信息
4. **库存日志**：每次成功导入都会生成相应的库存日志
