## 配置信息

### Waitress配置

```python
serve(
    app,
    host='0.0.0.0',      # 监听所有网络接口
    port=5003,           # 端口5003
    threads=4,           # 4个工作线程
    channel_timeout=30,  # 请求超时30秒
    expose_tracebacks=False  # 不暴露错误详情（安全）
)
```

### 优化建议

如果需要更高性能，可以：

1. **增加线程数**
   ```python
   threads=8  # 或更多，根据CPU核心数
   ```

2. **添加Nginx反向代理**
   ```
   用户 → Nginx → Waitress → Flask
   ```

3. **添加Redis缓存**
   - 缓存常用数据
   - 减少数据库查询

4. **数据库优化**
   - 添加索引
   - 优化查询
   - 使用连接池
