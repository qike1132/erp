## 五、测试框架使用指南

### 5.1 运行测试命令

```bash
# 运行所有测试
python -m pytest tests/ -v

# 运行单元测试
python -m pytest tests/unit/ -v

# 运行集成测试
python -m pytest tests/integration/ -v

# 运行功能测试
python -m pytest tests/functional/ -v

# 运行边界测试
python -m pytest tests/boundary/ -v

# 运行测试并生成覆盖率报告
python -m pytest tests/ --cov=. --cov-report=html

# 运行特定测试文件
python -m pytest tests/unit/test_models.py -v

# 运行带标记的测试
python -m pytest -m unit tests/
python -m pytest -m integration tests/
python -m pytest -m functional tests/
```

### 5.2 查看测试报告

- **HTML覆盖率报告**: `htmlcov/index.html`
- **XML覆盖率报告**: `coverage.xml`
- **终端报告**: 直接在命令行查看

### 5.3 运行质量分析

```bash
# 快速分析
python quality/quick_analysis.py

# 完整分析
python quality/run_analysis.py
```
