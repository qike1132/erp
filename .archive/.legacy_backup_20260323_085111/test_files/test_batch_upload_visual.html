批量上传功能修复验证

问题描述

在"/products"页面中，批量上传功能的点击操作没有任何响应。原因是点击事件冒泡到了父级的 Bootstrap collapse 组件，导致上传区域立即收起。

修复方案

在 excelUploadArea 的点击事件处理器中添加了 e.stopPropagation() 调用，阻止事件冒泡到父级元素。

修复代码示例

// 修复后的点击事件处理
excelUploadArea.addEventListener('click', (e) => {
    e.stopPropagation(); // ← 关键修复：阻止事件冒泡
    if (e.target.tagName !== 'IMG' && 
        e.target.id !== 'download-template' && 
        e.target.id !== 'batch-import') {
        excelInput.click();
    }
});

// 修复后的拖拽事件处理
excelUploadArea.addEventListener('dragover', (e) => {
    e.preventDefault();
    e.stopPropagation(); // ← 阻止事件冒泡
    excelUploadArea.classList.add('border-success', 'bg-success', 'bg-opacity-10');
});
