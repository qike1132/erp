# 新架构启动指南

## 启动方式

### 方式1: 直接运行（推荐）

```bash
python run.py
```

系统会自动使用新架构启动。

### 方式2: 使用Python模块方式

```bash
python -m run
```

### 方式3: 显式指定使用新架构

```bash
# Windows PowerShell
$env:USE_NEW_ARCH='true'
python run.py

# Linux/Mac
export USE_NEW_ARCH=true
python run.py
```

### 方式4: 使用旧架构（如果需要）

```bash
# Windows PowerShell
$env:USE_NEW_ARCH='false'
python run.py

# Linux/Mac
export USE_NEW_ARCH=false
python run.py
```

## 访问地址

启动成功后，可以通过以下地址访问：

- **本地访问**: http://127.0.0.1:5003
- **局域网访问**: http://192.168.0.95:5003

## 新架构特性

### 蓝图结构

- **main_bp**: 主页、登录、登出、兼容性路由
- **product_bp**: 产品管理（5个路由）
- **order_bp**: 订单管理（3个路由）
- **stock_bp**: 库存管理（7个路由）
- **api_bp**: API接口（10个路由）

### 总路由数

**33个路由**，包括：
- 主页和认证：3个
- 兼容性路由：5个
- 产品管理：5个
- 订单管理：3个
- 库存管理：7个
- API接口：10个

## 数据库配置

系统使用MySQL数据库：
- 数据库类型: MySQL
- 连接地址: localhost:3306
- 数据库名: erp_system
- 字符集: utf8mb4

## 注意事项

1. **端口占用**: 确保5003端口未被占用
2. **数据库连接**: 确保MySQL服务正在运行
3. **环境变量**: 确保.env文件中配置了正确的数据库密码
4. **调试模式**: 生产环境请关闭调试模式

## 停止服务

按 `Ctrl+C` 停止服务。

## 日志查看

启动日志会显示在控制台中，包括：
- 蓝图注册状态

- 访问地址
- 调试器PIN码
