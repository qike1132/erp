# 简单PRD：盲盒产品SKU层级面料BOM区分方案

> 输出者：产品经理（许清楚）· 软件开发团队
> 状态：已由架构师（高见远）作为方案设计输入
> 原始需求：为"Nommi糯米儿-宝藏收藏家系列毛绒盲盒"的面料BOM增加款式（style）层级

## 1. 项目信息

- 语言：中文
- 项目：自研ERP（FastAPI + Vite + Tkinter）BOM模块扩展，本次聚焦**面料（fabric）款式级拆分**
- 原始需求复述：为"Nommi糯米儿-宝藏收藏家系列毛绒盲盒"的面料BOM增加款式（style）层级，实现"SKU→款式→面料清单"的可追溯区分，支持6款/7款盲盒场景。

## 2. 产品定义

### 2.1 业务规则（产品语言）

- **SKU**：可售/可采购的最小库存单元（本系列1个SKU）。
- **款（style）**：盲盒SKU内部的隐藏款式，通常6款或7款（如 SKU-01…SKU-07），各款面料可能存在差异。
- **三者关系**：SKU(1) → 款(N) → 面料(M)。即一个SKU下先按款拆分，每款再挂自己的面料清单。
- **为什么现有一层"产品→面料1:N"不够**：现有模型只能表达"整个SKU共用一套面料"，无法表达"每款各用一套面料"。后果：面料用量无法按款核算 → 采购领料数量失真；某款改面料时无法定位影响范围；盲盒生产时无法按款备料。

### 2.2 User Stories

1. 作为**采购员**，我希望按款查看面料清单并汇总用量，以便按各款实际用量采购，避免多买/漏买。
2. 作为**生产计划员**，我希望盲盒按款排产时能一键调出该款BOM，以便准确领料和核算成本。
3. 作为**产品开发**，我希望区分公共面料与差异面料、共用面料只维护一次，以便降低重复维护与出错率。
4. 作为**质检/追溯人员**，我希望通过"SKU码+款号"定位任意款的面料记录，以便快速追溯质量问题的面料来源。

## 3. 技术规范

### 3.1 需求池

**P0（必须）**
- 面料BOM增加款式层级字段：款号 style_code（编码规则：SKU码-01/02…）、款式名称 style_name
- ProductFabric 增加 style_code / style_name 字段，面料记录按款拆分，每款独立可追溯
- 界面/表格按款区分标注：款号 + 款式名称对照，支持按款筛选

**P1（应该）**
- 公共面料与差异面料拆分：公共面料共享引用、不按款重复维护；差异面料按款独立维护
- 按款汇总面料用量：查询/汇总/导出按 style_code 聚合，输出与实际生产/采购一致
- 评估填充物/辅料是否做同构的款式级拆分（与面料同结构扩展）

**P2（可选）**
- 款式面料版本历史追溯（款式变更记录）
- 批量复制：复制SKU时批量生成6/7款面料记录
- 与生产工单/采购单联动校验（按款BOM与实际领料比对）

### 3.2 字段命名建议

| 字段 | 类型 | 说明 |
|---|---|---|
| style_code | string | 款号，如 NOMI-01 |
| style_name | string | 款式名称（对照表） |
| is_shared_fabric | bool | 是否公共面料 |
| style_usage | decimal | 该款面料用量 |
| style_sort | int | 款式排序（01-07） |

### 3.3 操作步骤（落地建议）

1. 后端 ProductFabric 增加 style_code/style_name/is_shared_fabric/style_usage 字段（可为空，兼容现有数据）
2. bom_service 的 get/save 增加按 style_code 的读写与校验
3. 前端/Tkinter 面料列表增加款号列与筛选下拉；新增"款式名称对照表"维护入口
4. 现有盲盒SKU数据补录款号后启用按款逻辑

## 4. 待确认问题（Open Questions）

1. 款号由系统自动生成（按SKU递增）还是人工维护？规则是否固定为"SKU码-01…"？
2. 同一SKU是否可能同时存在6款批次和7款批次？款数量变更时旧BOM如何处理？
3. 公共面料是否必须在每款下冗余记录，还是仅记录一次做共享引用？
4. 已录入的盲盒SKU面料数据是否需要迁移/补录款式信息，还是仅新数据生效？
5. 填充物/辅料本阶段就做款式级拆分，还是面料先行、后续扩展？
6. 按款汇总输出采购单时，公共面料用量如何合计（每款各算一次还是全局汇总一次）？
7. 是否允许若干款共用同一套"面料组"（即款间BOM完全相同）？还是每款必须独立记录？
8. 是否需要正式的"款号-款式名称"对照表维护界面，还是仅在BOM里内联维护？
