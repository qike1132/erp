## 1. 升级概述

### 1.1 升级背景

当前ERP系统在以下方面存在优化空间：

| 问题领域 | 现状描述 | 影响程度 |
|----------|----------|----------|
| **数据导入** | Excel文件编码不识别导致乱码 | 高 |
| **搜索功能** | 仅支持精确匹配，用户体验差 | 高 |
| **数据验证** | 手机号验证简单，不支持国际号码 | 中 |
| **日期处理** | 代码复杂，易出错 | 中 |
| **安全防护** | 用户输入未做XSS过滤 | 高 |
| **报表导出** | 功能单一，无图表支持 | 低 |

### 1.2 升级目标

| 目标 | 描述 | 预期收益 |
|------|------|----------|
| **提升数据质量** | 增强数据验证和格式化能力 | 数据错误率降低50% |
| **优化用户体验** | 拼音搜索、模糊匹配 | 搜索成功率提升30% |
| **增强安全性** | XSS防护、输入清理 | 安全等级提升1级 |
| **提高开发效率** | 简化日期处理等代码 | 开发效率提升25% |
| **扩展报表能力** | 支持图表、多格式导出 | 报表生成效率提升30% |

### 1.3 升级范围

本次升级共涉及 **27个** 新增依赖库，按优先级分为三个阶段：

| 阶段 | 库数量 | 时间周期 | 核心目标 |
|------|--------|----------|----------|
| **P0** | 12个 | 第1-2周 | 基础能力提升 |
| **P1** | 9个 | 第3-4周 | 功能增强 |
| **P2** | 6个 | 第5-6周 | 高级功能扩展 |

**代码变更示例**：
```python
# 变更前：复杂的日期范围计算
from datetime import datetime, timedelta
from calendar import monthrange

def get_month_range():
    now = datetime.now()
    start = datetime(now.year, now.month, 1)
    _, last_day = monthrange(now.year, now.month)
    end = datetime(now.year, now.month, last_day, 23, 59, 59)
    return start, end

# 变更后：简洁的arrow实现
import arrow

def get_month_range():
    now = arrow.now()
    return now.floor('month').datetime, now.ceil('month').datetime
```

```python
# 产品模型扩展
class Product(db.Model):
    name = db.Column(db.String(100))
    name_pinyin = db.Column(db.String(200))      # 全拼
    name_pinyin_abbr = db.Column(db.String(50))  # 首字母

# 保存时自动计算拼音
def save_product(product):
    product.name_pinyin = ''.join(lazy_pinyin(product.name))
    product.name_pinyin_abbr = ''.join([x[0] for x in lazy_pinyin(product.name)])
    db.session.commit()

# 搜索实现
def search_products(query):
    query_pinyin = ''.join(lazy_pinyin(query))
    query_abbr = ''.join([x[0] for x in lazy_pinyin(query)])
    
    return Product.query.filter(
        db.or_(
            Product.name.contains(query),
            Product.name_pinyin.contains(query_pinyin),
            Product.name_pinyin_abbr.contains(query_abbr)
        )
    ).all()
```
