## 1. 项目概述

### 1.1 项目背景

当前 ERP 系统使用数据库 `LIKE` 查询实现搜索功能，存在以下局限性：

| 局限性 | 影响 |
|--------|------|
| 性能瓶颈 | `%keyword%` 无法使用索引，大数据量时性能下降 |
| 功能缺失 | 不支持拼音搜索、同义词、纠错等高级功能 |
| 体验欠佳 | 搜索结果无相关性排序，无智能建议 |
| 扩展受限 | 新增搜索场景需重复开发 |

### 1.2 项目范围

**包含范围**：
- Elasticsearch 集群部署与配置
- 产品搜索、客户搜索功能升级
- 拼音搜索、搜索建议、搜索纠错功能
- 数据同步机制开发
- 监控告警体系建设

**不包含范围**：
- 其他实体搜索（供应商、物料等）- 后续迭代
- 机器学习推荐算法 - 后续迭代
- 移动端搜索优化 - 后续迭代

### 1.3 项目依赖

|--------|------|------|

```python
# fastapi_app/services/search_index_sync_service.py

class SearchIndexSyncService:
    """搜索索引同步服务"""
    
    def __init__(self):
        self.es_client = AsyncElasticsearch(settings.ES_HOSTS)
        self.sync_queue = asyncio.Queue()
    
    async def start(self):
        """启动同步服务"""
        await self._create_indices()
        asyncio.create_task(self._sync_worker())
    
    async def sync_product(self, product_id: int):
        """同步单个产品"""
        async with AsyncSessionLocal() as db:
            product = await db.get(Product, product_id)
            if product:
                doc = self._product_to_doc(product)
                await self.es_client.index(
                    index="products",
                    id=product.id,
                    document=doc
                )
```

```python
# fastapi_app/services/elasticsearch_product_search.py

class ElasticsearchProductSearchService:
    
    async def search_with_pinyin(self, keyword: str, limit: int = 20) -> list[dict]:
        """支持拼音的搜索"""
        query = {
            "query": {
                "bool": {
                    "should": [
                        # 精确匹配
                        {"term": {"barcode.keyword": {"value": keyword, "boost": 10}}},
                        # 名称匹配
                        {"match": {"name": {"query": keyword, "boost": 5}}},
                        # 拼音匹配
                        {"match": {"name.pinyin": {"query": keyword, "boost": 3}}},
                        # 模糊匹配
                        {"match": {"name": {"query": keyword, "fuzziness": "AUTO", "boost": 2}}}
                    ]
                }
            }
        }
        return await self._execute_search(query, limit)
```

**步骤2：搜索建议实现**

```python
async def get_suggestions(self, prefix: str, limit: int = 10) -> list[str]:
    """获取搜索建议"""
    query = {
        "suggest": {
            "product_suggest": {
                "prefix": prefix,
                "completion": {
                    "field": "suggest",
                    "size": limit,
                    "fuzzy": {"fuzziness": 1}
                }
            }
        }
    }
    response = await self.es_client.search(index="products", body=query)
    return [opt["text"] for opt in response["suggest"]["product_suggest"][0]["options"]]
```

## 8. 应对措施

### 8.1 技术风险应对

#### R1: ES集群故障

**应对策略**：多节点部署 + 自动故障转移 + 降级方案

```python
class HybridSearchService:
    """混合搜索服务（带降级）"""
    
    async def search(self, keyword: str) -> list[dict]:
        try:
            # 优先 ES
            return await self._search_es(keyword)
        except ElasticsearchException:
            # 降级到数据库
            logger.warning("ES不可用，降级到数据库搜索")
            return await self._search_db(keyword)
```

**预防措施**：
- 部署 3 节点 ES 集群
- 配置自动故障转移
- 实现健康检查和自动重启
- 准备降级方案

#### R2: 数据同步延迟

**应对策略**：实时 + 批量双通道同步

```python
class SyncService:
    async def sync_product(self, product_id: int):
        # 实时同步
        await self._realtime_sync(product_id)
        # 记录同步日志
        await self._log_sync(product_id)
    
    async def check_sync_lag(self):
        # 定期检查同步延迟
        lag = await self._calculate_lag()
        if lag > 30:
            await self._alert_sync_lag(lag)
```
