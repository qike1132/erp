# ERP 服务器管理器 — UI 重构设计方案（v7 · pywebview 路线）

> 版本：v7 设计方案 v1.0 ｜ 日期：2026-08-29
> 路线（已确认）：**B — pywebview 混合**。Python 业务层（进程管理/NSSM/日志队列/托盘/单实例/配置持久化）全部保留；UI 层改为 HTML/CSS/JS，经 pywebview(Edge WebView2) 装壳；**本 HTML 原型即最终 UI**。
> 硬性约束：功能逻辑与业务流程不变，仅重做 UI 与交互层。
> 参考体系：Ant Design 5.x / Arco Design / TDesign / Apple HIG（扁平、克制、分层仪表台）。

---

## 1. 设计目标

1. **专业感**：一眼可辨的"运维控制台"气质——数据驱动、克制、高效。
2. **信息层级**：同一时刻只有一个焦点任务（监控、启停、查日志、改配置、部署、处理告警）。
3. **零学习成本**：左侧导航 + 顶部全局状态 + 分区仪表台 + 表格明细，符合大厂管理工具心智。
4. **原型即产品**：HTML 原型直接成为 v7 最终 UI，消除"原型→实现"逐轮对齐成本。

## 2. 统一视觉规范（Design Token）

> 深色为默认主题（运维长时间盯屏），亮色一键切换；两套 Token 同构、语义一致。
> 中性色带轻微品牌色倾向；全部颜色语义化（颜色永远搭配图标/文字，不单独传达信息）。

### 2.2 字体层级（CJK 安全优先）

> 目标机 Windows Server 2019：无 Segoe UI Variable / Cascadia Mono；界面字体必须**中文优先**。

| 层级 | 字号/字重 | 字体 | 用途 |
| --- | --- | --- | --- |
| 页面标题 | 18px / 600 | 界面字体 | PageHeader |
| 统计数值 | 22px / 600 **等宽** | 等宽字体 | 监控统计卡 |
| 卡片标题 | 14px / 600 | 界面字体 | 卡片/区块标题 |
| 正文 | 13px / 400 | 界面字体 | 正文、表体 |
| 辅助 | 12px / 400 | 界面字体 | 说明、时间戳 |
| 代码/日志 | 12px **等宽** | 等宽字体 | 日志、端口、命令 |

- 界面字体栈：`"Microsoft YaHei UI","Microsoft YaHei","PingFang SC","Segoe UI",system-ui,sans-serif`
- 等宽字体栈：`"Cascadia Mono","Consolas","Microsoft YaHei Mono",ui-monospace,monospace`（日志/数字为主，中文回落 YaHei）

### 2.3 间距体系（8pt 栅格）

间距取 4 的倍数：`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40`。容器内边距统一 16~24；区块间垂直间距 24；卡片内元素间距 12~16。

### 2.4 圆角与阴影

| 档位 | 值 | 适用 |
| --- | --- | --- |
| 圆角-sm | 4px | 输入框、选择器、Segmented |
| 圆角-md | 6px | 按钮、Tag、Toast |
| 圆角-lg | 8px | 卡片、表格、面板 |
| 圆角-xl | 12px | 弹窗、Tooltip 浮层 |

阴影规则：**边框分层为主，阴影极轻**。浮层用 `0 4px 16px rgba(0,0,0,.12)`（深色）/`0 4px 12px rgba(0,0,0,.06)`（亮色）；常规卡片不设阴影，仅 1px 边框分层。

## 3. 布局优化（三段式框架）

```
┌────────────────────────────────────────────────────────────────────────┐
│ 顶栏 TopBar 52px                                                        │
│ [☰] 面包屑/页面标题      [模式徽章●] [API 5002][WEB 3000][Redis●] [主题][⚙]│
├──────────┬─────────────────────────────────────────────────────────────┤
│ 侧导航    │  主内容区（一屏一模块，页面级滚动）                            │
│ SideNav  │  ┌ PageHeader：标题 / 副标题 / 右侧操作区 ─────────────────┐  │
│ 208↔52px │  │                                                       │  │
│ ┌运行监控 │  │  页面内容（统计卡行 / 性能区 / 表格 / 表单 / 步骤条…）     │  │
│ ├服务管理 │  │                                                       │  │
│ ├日志中心 │  └───────────────────────────────────────────────────────┘  │
│ ├配置管理 │                                                             │
│ ├部署发布 │  ┌────────────────────────────────────────────────────────┐  │
│ ├告警中心 │  │ 状态栏 StatusBar 30px： [●运行中] 就绪 · 上次刷新 …      │  │
│ └──────── │  │                          [紧急停止] [窗口尺寸指示]        │  │
│  [收合 ◀] │  └────────────────────────────────────────────────────────┘  │
└──────────┴─────────────────────────────────────────────────────────────┘
```

**层级原则**：侧导航（唯一导航入口）→ 顶栏（全局状态：模式/端口/主题/设置）→ 页面头部（本页标题+操作）→ 内容区（信息表格+紧凑面板为主）→ 状态栏（全局反馈收敛）。任何操作结果写入 Toast + 状态栏，不打断当前视图。

### 3.1 六大页面结构

| 页面 | 内容结构 |
| --- | --- |
| 运行监控 | 4 统计卡（后端/Redis/前端/全局模式）→ 性能区 2:1（指标条+趋势图｜网络流量卡）→ 进程快照表 |
| 服务管理 | 开发/生产双卡（一键启动/一键重启/一键关闭 分行 + 进度条）→ 服务列表表（行 hover 显示操作） |
| 日志中心 | 工具条（级别 Segmented + 搜索 + 自动滚动 + 导出/清空）→ 日志查看器（级别着色、等宽） |
| 配置管理 | 左侧分组导航 176px → 右侧表单（脏标记 ●未保存 + 校验 + 重置/保存） |
| 部署发布 | 4 步 Stepper（校验→备份→部署→健康检查）→ 步骤日志 → 发布历史表 |
| 告警中心 | 告警列表（级别色点+Tag+描述+时间+确认）→ 批量确认 |

## 4. 组件规范（风格统一）

| 组件 | 规范要点 |
| --- | --- |
| **按钮 Button** | 5 变体：主按钮（brand 实底）/ 次按钮（面板底+边框）/ 文字按钮 / 危险按钮 / 链接按钮；圆角 6px；高度 32px；hover 150ms 缓变；loading 内嵌 spinner 禁点；disabled 45% 透明度 |
| **表单输入** | 高 32px；圆角 4px；focus 品牌色 1px 描边 + 2px 光晕；error 危险色描边 + 错误文案；success 校验通过；disabled 灰底 |
| **表格 Table** | 表头 13px/600 次文字色、底部分隔线；行 hover 悬浮底 + 操作列淡入（opacity 0→1，150ms）；选中行品牌 tint 底；斑马纹不使用 |
| **弹窗 Modal** | 圆角 12px；遮罩 45~60%；标题 16px/600 + 关闭 ×；页脚右对齐（次按钮+主按钮）；确认时主按钮 loading |
| **状态栏 StatusBar** | 高 30px；左：模式徽章+就绪文案+上次刷新；右：紧急停止（危险）+ 窗口尺寸指示 |
| **Toast** | 右上堆叠（宽 ~332px）；图标+标题+描述+关闭；成功/错误/警告/信息四型；3.2s 自动消失；不影响布局 |
| **Tag/徽章** | 语义色 tint 底 + 语义色文字，圆角 4px；状态点 6px 圆点（运行绿/停止灰/告警脉冲） |
| **Segmented** | 分段控件：选中项面板底+阴影+品牌文字；未选中透明 |
| **Stepper** | 完成（绿对勾）/进行（品牌圆点+脉冲）/未开始（灰）/失败（红叉）；步骤间 1px 连接线 |
| **空状态 Empty** | 40px 线性图标 + 说明文案 + 可选操作按钮（有教育意义） |
| **骨架屏 Skeleton** | 加载中：圆角块灰度呼吸动画，替代全屏 spinner |
| **Tooltip** | 深色浮层 12px 圆角、12px 文字，hover 150ms 淡入，箭头指向 |
| **进度条 Progress** | 4px 高、品牌色填充、圆角，进行中带流动动画 |

## 5. 交互反馈（状态矩阵）

| 状态 | 按钮 | 输入框 | 表格行 | 卡片/列表项 | 全局 |
| --- | --- | --- | --- | --- | --- |
| 默认 | 变体样式 | 边框灰 | 白底 | 面板底+边框 | — |
| 悬停 hover | 主色加深/底变深 | 边框加深 | 悬浮底+操作淡入 | 悬浮底+边框加深 | Tooltip 150ms |
| 按下 active | 主色再加深 | — | — | 按下微压（无位移动画） | — |
| 聚焦 focus | 描边光晕 | 品牌描边+光晕 | — | — | — |
| 加载 loading | spinner+禁点 | — | — | 骨架屏 | 状态栏"执行中…" |
| 禁用 disabled | 45% 透明 | 灰底禁点 | — | 操作置灰 | — |

| 成功 success | — | 对勾 | — | 状态点变绿 | Toast success + 状态栏 |

动效纪律：仅状态过渡（150~240ms ease-out），无位移动画、无弹性、无发光。

## 6. 响应式验证

| 断点 | 行为 |
| --- | --- |
| ≥1440px | 侧导航展开 208px；4 统计卡一行；性能区 2:1 |
| 1280~1439px | 侧导航自动收起 52px（悬浮 Tooltip 提示）；其余同上 |
| 1024~1279px | 统计卡 2×2；性能区改为上下堆叠 |
| <1024px（下限） | 统计卡 1 列；表格横向滚动 |

- 桌面窗口最小尺寸 1024×680（沿用 v6.0 语义）。
- 状态栏常驻**窗口尺寸指示**（如 `1280×800 · 断点 B`），缩放窗口时实时更新——便于开发期直接核验响应式是否生效。

## 7. pywebview 落地架构（编码阶段方案，本次不实施）

### 7.1 目录结构

```
gui_v7/
├─ main.py          # pywebview 窗口 + 生命周期（托盘/单实例/自启由业务层保留）
├─ bridge.py        # js_api 桥：暴露给 JS 的同步/异步方法（薄封装，业务全在 server_manager 层）
├─ server_core.py   # 复用 v6.0 ServerManagerApp 业务逻辑（去 Tk UI 后的核心类）
├─ web/             # 本原型拆分后的静态资源（index.html/style.css/app.js）
└─ requirements.txt # pywebview
打包：PyInstaller onefile + WebView2 Runtime 部署引导
```

### 7.2 桥接 API 面（映射 v6.0 既有方法）

| 分组 | JS 调用 | 对应业务（保留） |
| --- | --- | --- |
| 状态 | `getStatus()` | 模式徽章/端口/服务健康/心跳 |
| 监控 | `getMonitor()` | psutil 采样（CPU/内存/网络/磁盘/进程） |
| 服务 | `startDev/stopDev/restartDev`、`startProd/stopProd/restartProd` | 一键启动/互斥托管/进程树清理 |
| 生产 | `installServices/uninstallServices(workerN)` | NSSM 服务安装/卸载 |
| 日志 | `getLogs(query,level)`、`exportLogs()/clearLogs()` | 队列化日志（主线程零阻塞） |
| 配置 | `getConfig()/saveConfig(diff)/resetConfig()` | 配置持久化（JSON） |
| 部署 | `runDeploy()`（4 步进度回调） | 校验→备份→部署→健康检查（v6.0 P6 已实现） |
| 告警 | `getAlerts()/confirmAlert(ids)` | 告警列表与确认 |
| 系统 | `copyText()/minimize()/close()/openExternal()` | 端口复制/窗口控制 |

- 约定：JS 全部通过 `pywebview.api.xxx()` 异步调用；业务侧长任务走既有后台线程 + 队列，完成后 `window.pywebviewbridge` 回调推送；UI 线程零阻塞。

### 7.3 WebView2 Runtime 部署（唯一外部依赖）

- 官方支持 Windows Server 2019（17763+）。启动时检测注册表 `HKLM\SOFTWARE\WOW6432Node\Microsoft\EdgeUpdate\Clients\{F3017226-FE2A-4295-8BDF-00C3A9A7E4C5}`；
- 缺失 → 引导安装 Evergreen 离线安装器（随包分发，~100MB）；完全离线极端场景切换 Fixed Version 随包模式。
- 回退：v6.0 Tkinter exe 保留可运行，B 路线任一步骤失败可随时回退，零沉没成本。
