## 1. 整体风格(对应需求 1)

### 1.1 设计语言定位

```
视觉调性:专业 · 冷静 · 高密度信息 · 弱装饰
参考对象:Ant Design Pro 5 控制台 · 阿里云 ECS 控制台 · 字节跳动火山引擎 · 华为云 BMS · Apple macOS 系统设置
对立面:儿童化渐变 · 强投影 · 拟物 · 多彩图标
```

- **扁平化优先**:去除阴影滥用、渐变炫光、玻璃拟态(只在"需强调的悬浮元素"上做轻投影)
- **留白即层级**:用 8/16/24px 间距而非分隔线划分信息;**克制使用 `border`(只在卡片边缘、表头、输入框)**
- **品牌色克制**:主色仅用于(1)主操作按钮(2)选中态(3)关键数字(4)品牌识别位;**不铺满全屏**
- **状态色语义化**:绿=成功/运行,橙=警告,红=错误,青=信息,靛紫=处理中(loading/process);任何状态色必有对应图标或上下文
- **图标系统**:线性 1.6-1.8px 描边(Lucide 风格),18-20px,统一色相取自父元素 `currentColor`

### 1.2 主色板(品牌蓝)

| 色阶 | Hex | 用途 |
| --- | --- | --- |
| blue-50  | `#E6F0FF` | 极浅背景(选中行、悬浮) |
| blue-100 | `#C2D8FF` | 浅底(二级容器) |
| blue-200 | `#9DBEFF` | 禁用/辅助 |
| blue-300 | `#76A3FF` | 弱强调文字 |
| **blue-500** | **`#2F7BFF`** | **品牌主色 · 主按钮/选中/链接** |
| blue-600 | `#1F66E6` | 按下/激活 |
| blue-700 | `#1853BF` | 强强调(品牌文字) |
| blue-900 | `#0A2E73` | 极深(深色底色上的主元素) |

### 1.3 主题切换

- **暗色默认**(Server Manager 多在运维场景使用,暗色更聚焦信息)
- **亮色可选**(白天办公场景)
- 切换不重启动应用,实时套用 CSS 变量;记忆到 `server_manager_config.json`

| Token | 值 | 用途 |
| --- | --- | --- |
| `--r-xs` | 4px | 小徽章、tag |

| `--r-pill` | 999px | 胶囊徽章 |

> 圆角一致性:同一类组件永远用同一圆角(如所有 `Button` 用 `--r-md`,所有 `Card` 用 `--r-lg`)

### 3.4 间距(8 倍栅格 + 半档 4)

`--s-1=4  --s-2=8  --s-3=12  --s-4=16  --s-5=20  --s-6=24  --s-7=28  --s-8=32  --s-10=40  --s-12=48  --s-16=64`

**强制规则**:
- 组件内 padding:**最小 8px,常用 12/16/24**
- 组件间距:**最小 8px,常用 16/24**
- 模块间距:**24-32px**

### 3.5 阴影(Apple HIG material 原则)

| Token | 值 | 用途 |
| --- | --- | --- |
| `--sh-xs` | `0 1px 2px rgba(0,0,0,.16)` | 输入框 focus 弱投影 |
| `--sh-sm` | `0 2px 6px + 1px border` | Card 默认 |
| `--sh-md` | `0 6px 16px + 1px border` | 弹层、悬浮卡 |
| `--sh-lg` | `0 12px 32px + 1px border` | 模态框 |
| `--sh-focus` | `0 0 0 3px rgba(47,123,255,.25)` | 键盘 focus ring |

> **关键原则**:**深色背景下阴影 = `投影 + 1px 边框`**(Ant Design 暗色算法),否则阴影看不见

### 3.6 动效(Apple 节奏)

| Token | 值 | 用途 |
| --- | --- | --- |
| `--ease` | `cubic-bezier(.16,1,.3,1)` | 默认缓动(进入、悬浮) |
| `--t-fast` | 120ms | hover、color 切换 |
| `--t-base` | 200ms | 展开收起、弹层 |
| `--t-slow` | 320ms | 页面切换、模态进出 |

> **动效原则**:只动 `opacity / transform / color`,**不动画 width/height/top/left**;尊重 `prefers-reduced-motion`(用户开启系统减弱动效时禁用)

### 5.1 全局状态类型

| 状态 | 视觉变化 | 触发 | 动效 |
| --- | --- | --- | --- |
| **default** | 设计稿基线 | 初始 | — |

| **focus** | `box-shadow: --sh-focus`(3px 蓝色 ring) | Tab 键 / 聚焦 | 即时 |
| **disabled** | `opacity: 0.5; cursor: not-allowed` | 不可用 | — |
| **loading** | 旋转 spinner + 文字"加载中" | 异步操作 | 1.2s 循环 |
| **selected / checked** | 背景 `--brand-soft` + 左侧 3px 主色条 + 文字 `--brand` | 点击 | 200ms |
| **expanded** | 旋转 chevron + 内容展开 | 点击 | 200ms |
| **empty** | 空状态插画 + 标题 + 描述 + 主操作 | 无数据 | fadein 320ms |
| **error** | 1px 红色边框 + 错误文案 | 表单校验 / 接口失败 | 200ms shake |
| **success** | 绿色对勾 + 1.5s 自动消失 | 操作完成 | 200ms in / 1.5s hold / 200ms out |
| **processing** | 靛紫 + 旋转 + "处理中…" | 后台任务进行中 | spin 1.4s |

### 5.2 关键交互逻辑

#### 5.2.1 启动 / 重启 / 关闭流程(OneClickButtonGroup · ActionLock 互斥)

> 对应 `one_click_action.py`:`OneClickActionController` 统一调度,`ActionLock` 实现跨模式互斥与幂等。

**正常路径**:
1. 用户点击 `一键启动` / `一键重启` / `一键关闭` → 按钮变 spinner + 文字"启动开发模式·启动中…"
2. 控制器校验 `can_*`:`spec.running() and not in_flight()` 否则 Toast `warn` 拒绝
3. `ActionLock.acquire(key)` 原子占用 → 启动后台线程执行
4. 执行中:当前卡所有按钮 disabled,`busy_kind` 设值,UI 同步锁定
5. 完成:`_finish()` 收口 — 释放锁 → 复位 busy → 触发 on_success/on_failure → 刷新全局 UI
6. 成功 → 顶栏模式 Pill 切换 + 表格对应行状态变更;失败 → Toast `danger`

**跨模式互斥(关键)**:
- dev 与 prod 共享同一把 `ActionLock`(同一 owner 字段),任一模式执行"启动/重启/关闭"期间:
  - **另一模式的所有按钮自动 disabled**(防误操作)
  - 顶栏互斥提示:`alert.info` 横幅"正在 启动生产服务,请稍候"或"生产服务正在停止中,3 秒后可操作"
- 启动一方自动停另一方:点 dev 启动 → 控制器先触发 prod 停止 → 等 STOPPED → 再启 dev(避免端口/资源冲突)

**二次确认**:
- `一键关闭` 必须二次确认(Modal / 消息盒):"将停止开发模式,已提交的任务可能中断" / "将停止 erp-prod / erp-arq(保留 NSSM 注册)"
- `一键重启` 默认不确认(可由 `spec.confirm_restart` 开关控制,生产模式建议开启)
- `一键启动` 取决于当前状态:从"已停止"启动不需确认;从"运行中"误触不出现(按钮 disabled)

**视觉反馈**:
- 按钮 loading:38px 大按钮内 spinner 旋转 + 文字"开发模式·启动中…",disabled 视觉降级(opacity 0.7)
- 进度条:开发卡 5 步流程实时更新(停生产→清端口→Redis→后端健康检查→前端就绪)
- 顶栏:模式 Pill 即时切换(brand→success 或反向),不刷新页面
- 服务明细(NSSM):2s 轮询,服务状态在生产卡底部逐项更新

#### 5.2.2 部署流程

1. 点击 `开始部署` → **Modal 二次确认**:"将停服 N 秒,期间 API 不可用"
2. 确认 → Sticky 状态条出现,timeline 6 步逐步推进
3. 失败 → 任何一步红框告警 + 自动回滚 + Modal 显示日志
4. 成功 → 绿色对勾全亮 + Toast `success` + 自动跳到 `运行监控`

#### 5.2.3 实时数据刷新

- 指标卡 2s 刷新:数字 `<animate>` 数字滚动(120ms)避免突变
- 进程列表 5s 刷新:平滑过渡(行淡入淡出)
- 图表 1 个数据点 / 2s 追加,超 60 点左移
- **断线 / 降级**:顶部 Banner 红色 `alert.danger`:`监控数据采集失败,最后更新 xx:xx`

#### 5.2.4 搜索 ⌘K

- 任意页面 ⌘K → 全局搜索浮层(背景 mask,中央 600×480 卡片)
- 输入即搜(防抖 200ms),结果按"服务 / 命令 / 日志"分组
- 上下箭头切换、Enter 执行、Esc 关闭
- 历史记录(本地 5 条)

#### 5.2.5 主题切换

- 顶栏右侧 / 设置页 / 系统托盘菜单 → 即时切换,无刷新
- 配置实时写入 `server_manager_config.json`,下次启动恢复

#### 5.2.6 危险操作二次确认

- 全部停止 / 紧急停止 / 删除配置 / 回滚版本 → **Modal 二次确认**
- Modal 必须包含:操作影响范围 / 红色警告文案 / 取消(默认聚焦) / 确认(需用户主动点击)
- 输入式二次确认(回滚版本):需用户键入 `ROLLBACK` 6 字符才解锁按钮

#### 5.2.7 错误 / 失败统一处理

- API 调用失败 → 顶部 banner + 当前组件下方 `alert.danger`
- 日志区可一键展开查看详细堆栈
- 严重告警 → 顶栏铃铛 + 1,弹窗跳到 `告警中心`

### 5.3 动效原则(Apple HIG Motion)

1. **能用 0ms 解决的不用动效**(状态切换)
2. **进入用 ease-out,退出用 ease-in**(自然加速感)
3. **同时动不超过 2 个属性**(避免"乱动"感)
4. **尊重系统设置**:`@media (prefers-reduced-motion: reduce) { * { transition: none !important; animation: none !important; } }`

### 5.4 可访问性(a11y)

- 所有交互元素键盘可达(Tab 顺序)
- focus ring 永远显示(--sh-focus,3px 蓝色)
- ARIA:导航 `role=navigation`,状态 `aria-live=polite`,告警 `aria-live=assertive`
- 颜色对比度:正文 `--t1` vs `--bg-panel` ≥ 7:1(WCAG AAA)
- 不仅靠颜色:错误一定配图标 ✕ / 文案 / 红边
