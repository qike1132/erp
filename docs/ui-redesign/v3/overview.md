## 核心结论

1. **现状差距已识别**:v6.0.0 已有"三段式 + 暗色调"骨架,但服务图标五彩斑斓、状态徽章混乱、底部信息堆叠、图表留白粗放,**离 Ant Design Pro / Arco Design 级别还差 5-7 个关键细节**。
2. **完整 Token 体系已就绪**:14 类语义色 × 10 阶中性灰 × 4 档圆角 × 4 档阴影 × 6 档间距 × 9 档字号 × 2 主题(暗/亮) = 100+ 变量,全部用 CSS variables 表达。
3. **6 大模块全部有高保真样例**:`运行监控` / `服务管理` / `日志中心` / `配置管理` / `部署发布` / `告警中心` 在原型中均可点开查看,真实 SVG 图表 + 真实交互(侧栏切换、tab、状态徽章、Switch)。
4. **落地路径分两步**:
   - **短期(2 周)**:沿用 Tkinter,按文档 §6.3 步骤渐进替换为 V3 视觉,工作量 6-8 人天。
   - **远期(可选 1-2 月)**:Web 化(`/admin` 子模块,React + Tailwind + shadcn/ui),直接复用 Token + 组件。

## 关键设计决策一览

| 决策 | 方案 | 原因 |
| --- | --- | --- |
| 主题默认 | 暗色 | 运维场景多在控制台前,暗色聚焦信息 |
| 品牌色 | `#2F7BFF` 蓝 | ERP 行业惯例(企业级/可信/技术),与 Ant Design Blue 一致 |
| 主字体 | PingFang SC → 微软雅黑 UI → Segoe UI | 中英双轨 + Windows Server 字体回退 |
| 数字字体 | DIN Pro → Inter | 大数字显示更专业紧凑(Apple 数字风格) |
| 圆角档位 | 4/6/8/12/16/999 | 大厂只用 4-6 档(克制),避免随机 |
| 阴影策略 | 暗色下"1px 边框 + 轻投影" | 纯投影在暗底不可见,Ant Design 暗色算法 |
| 状态色 | 5 语义(成功/警告/错误/信息/处理中) + 中性 + 品牌 | 大厂通用,缺一不可 |
| 6 大模块切分 | 运行(监控+服务) / 运维(日志+配置+部署+告警) | 与 Ant Design Pro / 阿里云控制台一致 |
| 实时数据 | 数字滚动动效(120ms) + 图表增量 | 避免突变 + 视觉流畅 |
