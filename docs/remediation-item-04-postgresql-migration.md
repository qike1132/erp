# 整改项4：PostgreSQL 迁移 - 整改方案

## 一、问题描述

### 1.1 现状问题
- **MySQL 性能受限**：复杂查询、JSON 操作性能不足
- **asyncmy 停更**：MySQL 异步驱动已停止维护
- **JSON 支持弱**：无 JSONB 类型，JSON 查询效率低
- **高级特性缺失**：无物化视图、部分索引、全文搜索

### 1.2 影响分析
| 影响维度 | 具体问题 | 严重程度 |
|---------|---------|---------|
| 查询性能 | 复杂 JOIN 慢 | 🔴 高 |
| 驱动安全 | asyncmy 无维护 | 🔴 高 |
| JSON 操作 | 无 JSONB 支持 | 🟠 中 |
| 扩展性 | 无高级特性 | 🟠 中 |

## 二、整改目标

### 2.1 量化目标
| 指标 | 整改前 | 整改目标 | 验收标准 |
|------|--------|---------|---------|
| 复杂查询 | 80ms | ≤30ms | 基准测试 |
| JSON 查询 | 基准 | 快 5x | 对比测试 |
| 驱动维护 | 停更 | 活跃 | pip show 验证 |
| 停机时间 | N/A | ≤15 分钟 | 切换窗口 |

### 2.2 功能目标
- MySQL 8.4 → PostgreSQL 17
- 双写过渡（零停机）
- 数据 100% 一致性
- 死信队列 + 重放机制
