# 整改项2：依赖升级 - 整改方案

## 一、问题描述

### 1.1 现状问题
- **asyncmy 停止维护**：当前使用的 asyncmy (0.2.11) 已停止维护，存在安全漏洞风险
- **Celery 与 FastAPI 不匹配**：Celery 是同步任务队列，与 FastAPI 异步生态不兼容
- **orjson 性能瓶颈**：orjson 序列化性能已不能满足高并发需求
- **bcrypt 非 OWASP 推荐**：密码哈希算法需升级到 Argon2id

### 1.2 影响分析
| 影响维度 | 具体问题 | 严重程度 |
|---------|---------|---------|
| 安全风险 | asyncmy 停更，无安全补丁 | 🔴 高 |
| 性能瓶颈 | Celery 同步阻塞，影响 API 响应 | 🔴 高 |
| 资源占用 | Celery Worker 内存占用高 | 🟠 中 |
| 合规风险 | bcrypt 不符合 OWASP 2026 标准 | 🟠 中 |

## 二、整改目标

### 2.1 量化目标
| 指标 | 整改前 | 整改目标 | 验收标准 |
|------|--------|---------|---------|
| 驱动安全性 | 停更 | 活跃维护 | pip show 验证 |
| 任务延迟 | 180ms | ≤60ms | 压力测试 |
| JSON 序列化 | 8ms/10KB | ≤3ms/10KB | 基准测试 |
| 密码安全 | bcrypt | Argon2id | OWASP 合规 |

### 2.2 功能目标
- asyncmy → pymysql（阶段一过渡）→ asyncpg（阶段二）
- Celery → Taskiq 0.11.0
- orjson → msgspec 0.19.0
- bcrypt → argon2-cffi 23.1.0
