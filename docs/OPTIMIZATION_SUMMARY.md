## 🎯 使用指南

### 运行测试

```bash
# 运行所有测试并检查覆盖率
pytest tests/ -v --cov=. --cov-report=html

# 运行工具函数测试（已达标）
pytest tests/test_utils_complete.py -v

# 运行API路由测试
pytest tests/test_api_routes.py -v

# 运行E2E测试
pytest tests/e2e/ --e2e -v

# 查看覆盖率报告
open htmlcov/index.html
```

### 启用性能优化

在 `app/__init__.py` 中添加：

```python
from utils.redis_cache import init_redis_cache
from utils.compression import init_compression
from utils.cdn_config import init_cdn

def create_app():
    app = Flask(__name__)
    
    # 初始化性能优化
    init_redis_cache(app)    # Redis缓存
    init_compression(app)     # 请求压缩
    init_cdn(app)            # CDN支持
    
    return app
```

### 配置环境变量

在 `.env` 文件中添加：

```env
# Redis配置
REDIS_HOST=localhost
REDIS_PORT=6379
REDIS_DB=0
CACHE_TYPE=redis

# CDN配置
CDN_DOMAIN=cdn.yourdomain.com
CDN_HTTPS=true

# 压缩配置
COMPRESSION_MIN_SIZE=500
COMPRESSION_LEVEL=6
```
