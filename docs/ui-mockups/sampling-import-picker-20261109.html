「从打样单导入」弹窗改版对比

入口：采购页 / 产品页 → BOM 配置 → 「从打样单导入」。现状是必须先按产品名搜索才会出结果；改版目标：打开即自动列出打样间全部打样单（含产品图片），用户直接点选。生产库当前共 46 张（进行中 40 / 已完成 3 / 已取消 3，43 张有图），可一次性全量加载。

建议：方案 A（左卡片列表 + 右部位预览）。打样单选完就能在同一屏勾选要导入的部位，不用来回切换；左侧两列卡片保证图片可辨认，46 张滚动两屏内看完。搜索框保留为可选过滤，不再是必经步骤。
方案 A · 推荐

打开即全量列出：左侧图片卡片，右侧部位预览

弹窗打开后自动请求全部打样单（按更新时间倒序），无需输入关键词；点卡片立即读取该单最终版本部位，右侧勾选后一键导入。

  • 选单与勾部位同屏，少一次「预览 → 返回」往返
  • 卡片带产品图 + 状态徽标，扫一眼就能认出目标打样单
  • 搜索框保留：46 张时不是必需，数量增长后仍可快速过滤
