# ERP 服务器管理器 UI 重构规范（v4.1）

## 1. 目标与范围

本次重构仅覆盖 `server_manager.py` 的界面层，遵循以下原则：

- 严格保留现有功能逻辑、交互流程与进程管理行为
- 不修改任何业务执行路径（启动/停止/重启/日志流转）
- 仅优化视觉表现、组件风格与动效一致性

对应版本：`v4.1`

---

## 2. 设计原则

### 2.1 视觉方向

- 风格：专业、简约、高效率企业后台
- 色彩：以柔和中性色为基础，辅以单一品牌主色
- 层级：标题 > 卡片 > 操作区 > 日志区 > 状态栏
- 留白：统一间距体系（8/12/16/24）

### 2.2 交互方向

- 关键操作提供轻量反馈：
  - 按钮悬停与按下反馈
  - 卡片入场边框渐变
  - 状态栏指示灯呼吸动画（运行/忙碌）
- 动画时长控制在 150~350ms 范围，保证效率与流畅性

## 4. 组件规范

### 4.1 顶部 Header

- 高度：64px
- 左侧品牌：`ERP Server Manager`
- 中部：版本徽标（显示 `v4.1`）
- 右侧：固定端口信息

### 4.2 服务卡片

- 双列布局：调试模式 / 生产模式
- 顶部状态色条：
  - 调试：品牌蓝
  - 生产：成功绿
- 卡片元素：标题、描述、脚本名、状态、PID、操作按钮

### 4.3 按钮系统

- 统一圆角：8px
- 主按钮文字：白色
- 状态：默认/悬停/按下/禁用
- 保留原有命令绑定，不修改行为

### 4.4 日志卡片

- 标题：控制台 / 实时输出
- 操作：导出、清空
- 日志区域背景为浅中性色，增强可读性

### 4.5 状态栏

- 左侧：动态状态点 + 文本状态
- 右侧：地址信息
- 状态点根据运行状态做呼吸动画

---

## 5. 动效规范（统一）

### 5.1 窗口淡入

- 10 帧，20ms/帧，约 200ms 完成

### 5.2 卡片入场动画

- 每张卡片边框执行一次渐变脉冲
- 卡片间隔：80ms

### 5.3 状态点动画

- 运行中：绿色呼吸
- 忙碌中（启动/重启）：橙色且节奏更快
- 空闲：信息色轻呼吸

---

## 6. 响应式与性能说明

- 最小窗口：`800x600`
- 主内容区使用网格权重，随窗口尺寸自适应
- 动画全部基于 `after()`，无阻塞 I/O
- 不引入额外重量级依赖
