# 整改项6：Flask 遗留处理 + 安全加固 - 整改方案

## 一、问题描述

### 1.1 现状问题
- **Flask 遗留代码**：run.py 同时启动 Flask + FastAPI，Flask 代码冗余
- **密码哈希过时**：使用 bcrypt，不符合 OWASP 2026 标准
- **Cookie 不安全**：SameSite 配置缺失，跨域风险
- **日志不可观测**：无结构化日志，故障排查困难

### 1.2 影响分析
| 影响维度 | 具体问题 | 严重程度 |
|---------|---------|---------|
| 代码冗余 | Flask 代码不再使用 | 🟠 中 |
| 安全合规 | 密码哈希不达标 | 🔴 高 |
| 跨域安全 | Cookie 泄露风险 | 🟠 中 |
| 运维效率 | 日志不可搜索 | 🟠 中 |

## 二、整改目标

### 2.1 量化目标
| 指标 | 整改前 | 整改目标 | 验收标准 |
|------|--------|---------|---------|
| 密码安全 | bcrypt | Argon2id | OWASP 合规 |
| Cookie 安全 | 无 SameSite | SameSite=None+Secure | 配置验证 |
| 日志可观测 | 0% | 100% | Loki 查询 |
| 代码冗余 | Flask 存在 | Flask 下线 | 代码删除 |

### 2.2 功能目标
- Flask 进程停止，代码归档
- Argon2id 密码哈希
- Cookie SameSite 配置
- Loki 日志聚合
