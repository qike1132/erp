# ERP 3000 端口启用 HTTPS 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 ERP 生产入口 3000 端口从明文 HTTP 改为 HTTPS（复用现有自签内部 CA），并同步修正三处会因此误报的本机健康探针与离线部署包验收。

**Architecture:** nginx 的 3000 server 块加 `ssl` 监听 + 证书指令（与既有 443 块同构）；后端启动器 `prod_runner`、运维 `watchdog`、诊断 `runtime_mode_probe` 三处 `http://127.0.0.1:3000` 探针改为 https 并信任 `config/tls/ca.crt`；离线安装包安装后验收同步改 https。前端无需改动（API 走相对路径、WS 按页面协议自动选 ws/wss）。

**Tech Stack:** nginx（Windows 官方版，无 upstream keepalive 模块）、Python 3.13 标准库（urllib/ssl）、Vue 3 前端（不改）、PowerShell 5.1 部署脚本、pytest。

**Spec:** [docs/superpowers/specs/2026-10-09-erp-3000-https-design.md](../specs/2026-10-09-erp-3000-https-design.md)

## Global Constraints

- **这台机器既是生产主机也是运维主机**（AGENTS.md §0）：改动小步、可回滚；提交前跑质量门禁。
- **3000 只跑 TLS，不留 301 缓冲**（用户已定）：`http://<IP>:3000` 立即失效是既定代价。
- **探针信任内部 CA 文件** `config/tls/ca.crt`（用户已定），不导系统信任库、不 `CERT_NONE`。
- **watchdog 必须零项目依赖**（其 docstring 硬约束：FastAPI/Redis/PG 全挂时仍要能跑）——不得 import `fastapi_app.*`；CA 信任逻辑在 watchdog、runtime_mode_probe 内**各自内联**（约 8 行），这是刻意的重复，不是疏漏。
- **路径一律相对项目根解析**（`Path(__file__)...` / `ROOT` / `REPO_ROOT`），不得硬编码 `D:\erp_system`（CI 在 Linux 跑，见 `test_request_body_limit_paths.py` 的既有模式）。
- **改后必须提权重载 nginx**：非提权 reload 静默失败、退出码仍 0（见记忆 `erp-prod-restart-verification`）。验证以实测响应为准，不信退出码。
- **私钥留在库**为既有现状（`config/tls/*.key`），本次不新增风险，也不在此任务轮换。
- 提交信息写**为什么**；一个提交只做一件事；用 `git commit -- <路径>` 只提交自己的文件（并发会话会污染共享 index，见记忆 `quality-gate-blocked-by-concurrent-sessions`）。
- 本仓 shell 有 `_lc` 别名故障：Bash 工具里命令前加 `command`（见记忆 `bash-tool-broken-lc-alias`）。

## Review Focus

以下是最可能咬人的输入/失败模式，均已在对应任务写了测试：

1. **CI（Linux、干净检出）没有 `config/tls/ca.crt`** —— 探针/助手不得崩溃或假死，须优雅降级为"无 CA 则回退默认 context"并把缺失留痕。→ Task 2/3/4 的"缺文件返回 None"用例。
2. **既有 http 探针不能被误伤** —— `_http_ok` 仍须能探 `http://127.0.0.1:5002/api/health` 与任意明文 http（SPA 回退对照测试）。→ Task 2 的 http 回归用例。

"""内部自签 CA 的 TLS 信任上下文。

3000 端口改 TLS 后，本机健康探针需以 https 访问 https://127.0.0.1:3000，
而 nginx 用自签证书（签发者 = config/tls/ca.crt）。urllib 默认 HTTPSHandler
用系统信任库校验证书必然失败；本模块给出信任该 CA 的 SSLContext。
"""
from __future__ import annotations

import ssl
from pathlib import Path

PROJECT_ROOT = Path(__file__).resolve().parent.parent.parent
CA_CERT_PATH = PROJECT_ROOT / "config" / "tls" / "ca.crt"


def internal_ca_ssl_context() -> ssl.SSLContext | None:
    """信任 config/tls/ca.crt 的 SSLContext；CA 文件缺失时返回 None。

    返回 None 时调用方应回退默认 context，并把"缺 CA 文件"作为可诊断信号
    留痕——探针不得因配置文件缺失而静默假死（CI 干净检出即此情形）。
    """
    if not CA_CERT_PATH.is_file():
        return None
    return ssl.create_default_context(cafile=str(CA_CERT_PATH))

from __future__ import annotations

import importlib.util
import ssl
import threading
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer
from pathlib import Path

import pytest

_RP = _REPO / "scripts" / "diag" / "runtime_mode_probe.py"
_CRT = _REPO / "config" / "tls" / "server.crt"
_KEY = _REPO / "config" / "tls" / "server.key"

    spec = importlib.util.spec_from_file_location("erp_runtime_probe_under_test", _RP)
    mod = importlib.util.module_from_spec(spec)
    spec.loader.exec_module(mod)

class _NginxLike(BaseHTTPRequestHandler):
    def do_GET(self):  # noqa: N802
        b = b'<!doctype html><script src="/assets/index-abc.js"></script>'
        self.send_response(200); self.send_header("Server", "nginx")
        self.send_header("Content-Length", str(len(b))); self.end_headers()
        self.wfile.write(b)
    def log_message(self, *a): pass


def test_probe_frontend_over_https(monkeypatch) -> None:
    if not (_CRT.is_file() and _KEY.is_file()):
        pytest.skip("无 config/tls 证书（干净检出）")
    srv = ThreadingHTTPServer(("127.0.0.1", 0), _NginxLike)
    ctx = ssl.SSLContext(ssl.PROTOCOL_TLS_SERVER); ctx.load_cert_chain(str(_CRT), str(_KEY))
    srv.socket = ctx.wrap_socket(srv.socket, server_side=True)
    t = threading.Thread(target=srv.serve_forever, daemon=True); t.start()

        monkeypatch.setattr(mod, "WEB_PORT", srv.server_address[1])
        out = mod.probe_frontend()
        assert out.get("verdict") != "probe_unknown", out
        assert out.get("status") == 200
