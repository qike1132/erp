# 2026-08-11 工作记录

## beile-order 搜索输入时表格/输入闪烁修复（数据驱动定位 ✅）

**用户反馈**：删除文字闪烁已修复，但搜索「变形金刚」逐键输入时，打一次字 → 表格闪烁一次，输入框也闪烁。

**诊断（浏览器 MutationObserver + 元素几何测量，非猜测）**：
1. **输入闪烁**：PrimeVue AutoComplete 每次键入后约 300ms 触发搜索，搜索期间输入框内出现旋转 spinner（实测出现约 400ms）→ 逐键转圈闪烁。
2. **表格闪烁**：建议面板挂载于输入框正下方（top≈74），实测覆盖「查询/重置」按钮行与表格顶部约 2 行（面板 bottom≈197 > 表格 top≈131）；面板每次挂载/结果更新都会重播 PrimeVue `p-anchored-overlay` 300ms 缩放淡入动画 → 视觉上表格区域逐键闪烁。
3. 表格行本身在自由键入期间不变（「输入与筛选解耦」修复有效），闪烁全部来自面板 + spinner。

**修复（3 文件）**：
- `UiAutocomplete.vue`：新增 `searchDelayMs`（默认 300，透传 PrimeVue `delay`）、`showLoading`（默认 true）两个可选 prop，向后兼容其他 4 处调用。
- `BeileOrderView.vue`：产品/客户两个 UiAutocomplete 均传 `:search-delay-ms="500"` + `:show-loading="false"`。
- `app.css`：全局禁用 `.p-anchored-overlay-enter/leave-active` 动画（`animation: none !important`），下拉面板瞬时显示。

**效果（预览实测）**：
- spinner 出现次数 0；面板仅在用户停顿 500ms 后打开一次（不再逐键挂载）；面板瞬时出现无动画。
- 键入期间表格行数不变（0 次 tbody mutation）。
- 选中「变形金刚」后表格正常过滤为 9 行并显示产品名称列；查询/重置正常；清空输入恢复下拉；选中后编辑/删除文字不再弹面板（删除闪烁修复保持有效）。

**遗留观察**：面板打开时仍会覆盖「查询/重置」按钮行（下拉面板固有行为），点击需先关闭面板；未改动。
