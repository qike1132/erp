============================================================================
  步骤 1: 手动构建真实 APK
============================================================================

请打开一个 PowerShell 或命令提示符窗口，在 d:\erp_system\android-app 目录下执行：

  cd d:\erp_system\android-app
  .\gradlew.bat assembleRelease

这会执行完整的 Release 构建，包括：
  - 代码编译
  - 资源打包
  - ProGuard 代码混淆和压缩
  - 使用 release.keystore 签名


============================================================================
  步骤 2: 找到构建好的 APK
============================================================================

构建成功后，APK 文件会在这个位置：

  d:\erp_system\android-app\app\build\outputs\apk\release\

文件名通常是：
  app-release.apk


============================================================================
  步骤 3: 自动发布 (使用我们的脚本)
============================================================================

找到 APK 后，可以使用我们的完整发布脚本：

  cd d:\erp_system
  python scripts\build_and_release.py --skip-build --apk-path "d:\erp_system\android-app\app\build\outputs\apk\release\app-release.apk" --changelog "修复Dashboard统计、APK版本显示、FCM通知" --publish

这会：
  - 读取当前版本信息 (1.2, code=76)
  - 计算 MD5 校验
  - 上传到后端 API
  - 自动发布 (如果指定了 --publish)
  - 复制到 static/releases/ 目录


============================================================================
  步骤 4: 验证发布
============================================================================

1. 打开管理界面: http://192.168.0.95:3000/app-update
2. 确认看到 v1.2 版本显示为「已发布」绿色标记
3. Android 设备应该会收到 FCM 推送通知 (如果已配置)


============================================================================
  APK 下载地址
============================================================================

发布成功后，APK 可以通过以下 URL 直接下载：
  http://192.168.0.95:5002/static/releases/erp-v1.2.apk


============================================================================
  故障排除
============================================================================

如果构建失败，先尝试：

1. 清理构建:
   cd d:\erp_system\android-app
   .\gradlew.bat clean

2. 检查 Java 版本 (需要 JDK 17):
   java -version

3. 检查本地签名配置 (local.properties 中的 keystore 配置):
   - 确保 release.keystore 文件存在
   - 确保密码配置正确
