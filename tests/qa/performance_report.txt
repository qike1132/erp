优化措施:
1. 同步版库存查询: selectinload全量加载 → SQL GROUP BY聚合
2. 客户列表: 全量返回 → 服务端分页+搜索
3. 供应商搜索: 无limit → 限制50条
4. 供应商active-names: 无缓存 → Redis缓存300s
5. 库存接口: 全量返回 → 服务端分页+国家过滤
6. 库存日志: 全量返回 → 分页50条/页
7. available-stockins: 无limit → 限制100条
8. 前端InventoryTab: customOrderDetails模板方法 → 预处理_custom_details
9. 前端CustomerView: 客户端分页 → 服务端分页+搜索防抖
