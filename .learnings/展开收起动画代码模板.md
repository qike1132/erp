# 展开/收起动画代码模板 - 学习文档

**创建时间**: 2026-03-20  
**应用场景**: ERP 系统备货管理页面 - 流水记录展示  
**技术栈**: Bootstrap 5 + Font Awesome + CSS3

---

## 功能概述

在表格中实现可展开/收起的详情展示功能，用于显示备货记录的抵扣流水详情。

### 核心特性
- ✅ 点击展开按钮显示详情
- ✅ 按钮图标旋转 180°动画
- ✅ 平滑的展开/收起动画
- ✅ 支持多个记录同时展开
- ✅ 响应式设计（小屏幕隐藏列）
- ✅ 滚动条美化
- ✅ 最大高度限制（300px）

## 2. CSS 样式

### style.css
```css
/* 展开按钮图标旋转动画 */
.toggle-icon {
  transition: transform 0.3s ease;
}

/* 展开状态：图标旋转 180 度 */
[data-bs-toggle="collapse"][aria-expanded="true"] .toggle-icon {
  transform: rotate(180deg);
}

/* Bootstrap collapse 组件样式修正 */
.collapse:not(.show) {
  display: none;
}

/* 表格行内的 collapse 需要 display: table-row */
.collapse.show {
  display: table-row;
}

/* 响应式：小屏幕隐藏产品图片列 */
@media (max-width: 768px) {
  .product-col {
    display: none;
  }
  
  table.table td:nth-child(4),
  table.table th:nth-child(4) {
    display: none;
  }
  
  table.table td:nth-child(5),
  table.table th:nth-child(5) {
    min-width: 100px;
  }
}

/* 滚动条美化 */
div[style*="max-height"]::-webkit-scrollbar {
  width: 6px;
}

div[style*="max-height"]::-webkit-scrollbar-track {
  background: #f1f1f1;
  border-radius: 3px;
}

div[style*="max-height"]::-webkit-scrollbar-thumb {
  background: #87CEEB;  /* 浅蓝色 */
  border-radius: 3px;
}

div[style*="max-height"]::-webkit-scrollbar-thumb:hover {
  background: #B0E0E6;  /* 更浅的蓝色 */
}
```

from sqlalchemy.orm import joinedload

@app.route('/items', methods=['GET', 'POST'])
def items():
    if request.method == 'POST':

## 4. 关键要点

### 4.1 Bootstrap 5 Collapse 组件
- **触发器**: `data-bs-toggle="collapse"` + `data-bs-target="#target-id"`
- **目标元素**: `class="collapse"` + `id="target-id"`
- **状态属性**: `aria-expanded="false"` (初始收起)

### 4.2 表格内的 Collapse 特殊处理
```css
/* 表格行中的 collapse 需要特殊处理 */
.collapse.show {
  display: table-row;  /* 不是默认的 display: block */
}
```

### 4.3 图标旋转动画
```css
/* 初始状态 */
.toggle-icon {
  transition: transform 0.3s ease;
}

/* 展开状态 */
[data-bs-toggle="collapse"][aria-expanded="true"] .toggle-icon {
  transform: rotate(180deg);
}
```

### 4.4 嵌套表格布局
- 外层 `<td>` 使用 `colspan` 跨越所有列
- 内层使用独立的 `<table>` 展示详情
- 背景色区分层级（#F8F9FA）

### 4.5 性能优化
- 后端使用 `joinedload` 预加载关联数据
- 避免模板渲染时的 N+1 查询
- 前端使用 CSS 动画而非 JS 动画

## 7. 常见问题

### Q1: 展开后表格错位？
**A**: 确保内层 `<td>` 的 `colspan` 值等于外层表格的列数

### Q2: 图标不旋转？
**A**: 检查 CSS 选择器优先级，确保 `[aria-expanded="true"]` 选择器优先级足够

### Q3: 多个展开同时显示？
**A**: Bootstrap collapse 默认支持多个同时展开，无需额外配置

### Q4: 滚动条不显示？
**A**: 确保内容超过 `max-height` 设置的值

### Q5: 响应式布局不生效？
**A**: 检查 `@media` 查询的断点值和 `nth-child` 选择器是否正确
